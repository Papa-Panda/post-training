## 一句话总结
RL 阶段不用堆 8k 题，用 Learning Impact Measurement 按学习轨迹挑 1,389 题硬题，7B RL 效果反超全量，证明 RL 里少即是多就是影响力对齐。

## 核心
1.  **Motivation**: o1, R1 都说 RL 能提推理，但数据要多少说不清。SFT 少量好用的 LIMO/s1 在 7B 上拉胯，说明 SFT 的少即是多不能直接搬到 RL。
2.  **Data Pipeline**: 从 base 模型直接起 RL -> 跑全量 8,523 题轨迹 -> 用 LIM 评估每题和学习轨迹的对齐度 -> 挑 1,389 -> 再训 RL 对比。LIM 是自动化度量，算每题对策略提升的贡献。
3.  **Key Tricks**: 
    - 不蒸馏直接从 base RL：避免老师天花板
    - LIM 按轨迹对齐度选，不是按难度主观：1,389 vs 8,523 打赢【8617116200514826664†L20-L23】
    - 小样本 RL 泛化更好：AIME24 +16.7%，MATH500 超 LIMO 13% / s1 22.2%【8617116200514826664†L23-L26】
4.  **Results**: 1,389 题 LIMR-7B 在 AIME/MATH 上持平或超过 8,523 全量【8617116200514826664†L21-L24】，开源了 LIM 实现+数据+模型【8617116200514826664†L26-L29】。

## 第二轮复习（2026-09-11）

> 本轮已对照原文全文核对：arXiv 2502.11886（ar5iv 全文，§1–§4）。初读 NOTES 只有 37 行、未含 LIM 公式与实验细节，本轮补齐全部关键数字与训练配置，并纠正两处初读表述。

### 1. 核心命题

Day 11 真正解决的 data 问题，不是"RL 要多少数据"，而是：**RL 阶段的数据价值判据必须从静态切换到动态**。SFT 时代的判据（Day04 LESS 的梯度对齐、Day12 SuperFiltering 的难度、Day20 DEITA 的质量×复杂度）都是在训练开始前对文本算一次的静态分；但 RL 里一条数据的价值，是它在训练过程中实际推动策略提升的量——这个量在静态下不可见，只能在学习轨迹里读出来。

LIMR 的核心命题因此是：**RL 数据的价值 = 样本学习轨迹与模型整体学习轨迹的对齐度**，而不是样本的内在难度、质量或文本属性。1,389 题打赢 8,523 全量（Table 2：AIME24 32.5 持平全量、MATH500 78.0 反超全量 76.6、AMC23 63.8 反超 61.9）的本质，是把 rollout 预算集中到"模型正在学会、且学得动的题"上，砍掉两类纯噪声：太难（轨迹长期 near-zero，梯度信号被 -1 格式惩罚淹没）、太简单（开局即高 reward，策略已收敛、无更新量）。这与 LESS 的"定向集中"同构，但 LESS 的参照系是**目标梯度**（先验、静态），LIM 的参照系是**学习轨迹**（后验、动态）——RL 把"数据价值"从"文本属性"彻底变成了"训练过程属性"。

一句话：Day 11 是"少即是多"从 SFT 搬到 RL 时必须换判据的存在性证明——判据不换（直接套 LIMO/s1 的静态难例），7B 上会直接拉胯（§3.3）。

### 2. 图谱位置

- **直接前驱 Day04 LESS（重点直接对比）**：同一"少即是多"谱系，判据一静一动。LESS 的问题是"这条数据若被训一步，目标 loss 降多少"（Taylor 展开的一步反事实，静态、一次算完、可复用）；LIM 的问题是"这条数据的学习曲线长得像不像模型整体的学习曲线"（整条轨迹的形状对齐，动态、必须先跑完一轮全量）。记号对照：LESS 的 $\Gamma(z)$ 是**一步更新方向**，LIM 的 $r_i^k\ (k=1..K)$ 是**K 个 epoch 的 reward 序列**。工程含义：LESS 建一次梯度库可反复用（便宜、可复用），LIM 必须先付一轮全量 RL 的沉没成本（贵、但信号更贴近 RL 现实）。两者互补而非替代：LESS 适合"训练前定配比"，LIM 适合"第一轮跑完后定复训集"。
- **重点对比 Day17 LIMO / Day18 s1**：论文 §3.3 亲手做了这个对照实验——把 LIMO 的 817 题、s1 的 1,000 题直接拿来 SFT Qwen2.5-Math-7B，结果 AIME24 都是 15.8（s1 的 MATH500 只有 55.8，甚至低于 base 的 52.4 没多少），而 LIMR 的 RL 路线做到 32.5 / 78.0。论文原话："in scenarios with limited data and small models (e.g., 7B models), using RL is more effective than distilling data from larger models and performing imitation learning"。深层分野：LIMO/s1 的数据是 **32B teacher 蒸馏的长 CoT**——SFT 是在"背诵" teacher 的推理路径，7B 容量不够，长 CoT 背不下来反而干扰；RL 是模型**自己探索**出适合自己容量的推理路径。教训：SFT 的"少即是多"依赖 teacher 数据质量（蒸馏天花板），RL 的"少即是多"依赖数据与学习过程的匹配——**判据跟着优化范式走，SFT 的配方不能直搬 RL**（这正是初读 Motivation 里写对了的一句）。
- **后继 Day15 R1 / Day28 Open-Reasoner-Zero**：LIMR 是 R1-zero 范式的"数据选择"支线（base 起始、无蒸馏、纯 RL、可验证奖励）；Day28 的动态采样（难度分层 + 在线重采样）是对 LIM"静态一次性选"的在线化——LIM 选完 1,389 就固定了，Open-Reasoner-Zero 让选择跟着训练走（见 §6 思考题 b）。
- **替代/互补**：
  - vs Day12 SuperFiltering：LIM 的"静态简化版"。SuperFiltering 用 125M 弱模型的 IFD 一次性筛难度（先验、便宜）；LIM 用全量 RL 轨迹筛对齐度（后验、贵）。两者都验证了"选择信号可迁移"，但筛的不是同一种东西。
  - vs Day13 DPO-Gap：同一条"post-train 全链路筛选"线的两段——Day13 筛 **preference pair**（难对留 10%），Day11 筛 **RL 样本**（轨迹对齐留 16%）。供给侧（Day10 的 6 轮生产 pairs）+ 筛选侧（Day13/11）合起来才是完整故事。
  - vs Day05 DataInf：DataInf 是"每条样本对 test loss 的近似精确影响分"（1 秒一条，扫脏用）；LIM 是"每题的学习曲线形状分"（整轮轨迹，选题用）。一个回答"这条数据是好是坏"，一个回答"这条数据现在学不学得动"。

### 3. 机制深挖

记号（全部先定义）： $N=8{,}523$ 为 MATH-FULL 总题数（MATH levels 3–5）； $K$ 为 RL 总 epoch 数； $r_i^k\in\{1,-0.5,-1\}$ 为样本 $i$ 在第 $k$ 个 epoch 的**规则奖励**（§2.4：答案正确=1；答案错但格式对=-0.5；格式错=-1）； $r_{\text{avg}}^k=\frac{1}{N}\sum_{i=1}^N r_i^k$ 为第 $k$ 个 epoch 全样本的**平均奖励曲线**（模型整体学习进展的代理；神经网络学习呈对数增长，平均曲线即"标准学习形状"）。

**(a) LIM 公式的几何含义（§2.2.1）。**

$$\text{s}_{i}=1-\frac{\sum_{k=1}^{K}(r_{i}^{k}-r_{\text{avg}}^{k})^{2}}{\sum_{k=1}^{K}(1-r_{\text{avg}}^{k})^{2}},\qquad i=1,\dots,N$$

分子：样本 $i$ 的 reward 轨迹偏离平均轨迹的平方和——"这题的学习节奏跟大部队差多远"。分母：**理想轨迹**（每个 epoch reward 恒为 1，即"从第一轮就全对"）偏离平均轨迹的平方和——归一化因子，把分数缩放到以 1 为上界。 $s_i=1$ 表示轨迹与平均轨迹完全重合； $s_i$ 越小（可为负）表示偏离越大。选择规则： $s_i>\theta$ ，论文取 $\theta=0.6$ ，筛出 1,389 题（§2.2.2）。

为什么参照系是"平均轨迹"而不是"单调上升"：论文还试了 LINEAR baseline（§2.3， $\theta=0.7$ →1,138 题，奖励"每个 epoch 稳步提升"的样本），结果 MATH500 74.6 < LIMR 78.0。LINEAR 漏掉了"早期快涨、后期稳定"的样本——这类题恰好是"模型快速掌握的核心技能题"，线性假设把它们当"后劲不足"扔掉了。LIM 的平均轨迹参照保住了它们：只要形状像大部队（快涨后稳），分就高。**"像平均"在这里是褒义：意味着这题的可学习性与模型当前能力节奏合拍。**

**(b) 三类轨迹的命运（Fig 2a）。** 论文把 8,523 条轨迹分成三类：① 长期 near-zero（太难：reward  mostly -1/-0.5，策略梯度被格式惩罚噪声淹没，学不动）；② 开局即高 reward（太简单：策略已收敛，优势函数≈0，无更新量）；③ 动态进步（ $r_i^k$ 沿 $r_{\text{avg}}^k$ 爬升——被选中的 1,389 主体）。LIM 的本质是**自动化的"最近发展区"（zone of proximal development）筛选**：只留"跳一跳够得着"的题。这比人工定难度阈值高明在：阈值是静态的，"够得着"是模型相关的、随训练变化的。

**(c) 训练配置与实验设计（§3.1，初读完全遗漏）。** 算法 PPO（OpenRLHF 实现）；起点 Qwen2.5-Math-7B（论文 Table 1 标注 Init Model=Base、无蒸馏冷启动；注意这是数学域 continual-pretrained 的模型，不是通用 raw base——"无蒸馏"成立，"base"不如 R1-zero 干净）；rollout batch 1,024、每 prompt 采样 8 个、温度 1.2；训练 batch 256；actor lr $5\times10^{-7}$ 、critic lr $9\times10^{-6}$ ；KL 系数 0.01。评测：AIME24（30 题，每题 4 次采样、温度 0.4）、AMC23（40 题同）、MATH500（greedy）。对照组：FULL（8,523）、RAND（随机 1,389：25.8/66.0/56.3/49.4，avg 49.4——证明"少"本身不值钱，值钱的是"选得对"）、LINEAR（1,138）。

**(d) 训练动态的副产品发现（Fig 3b/3c，初读遗漏）。** FULL 训练的响应长度曲线**不稳定**（忽长忽短），LIMR 的长度**先降后升**（先压缩掉无效长推理，再随能力恢复增长）；LIMR 的 reward 曲线上升更快、最终接近 1.0。数据视角的翻译：全量里的噪声题（太难/太简单）在持续制造"长度抖动"——模型在无效探索上浪费 rollout；精选集让"长度"重新变成能力的单调函数。这是"数据选择稳定训练动态"的直接证据，也是 §5 迁移实验里"省 rollout"的理论依据。

### 4. 边界与反例

1. **LIM 是后验方法：第一轮的全量成本没省。** $r_i^k$ 轨迹必须先在 8,523 全量上跑完一轮 RL 才有。严格的成本账：LIMR 总成本 = 全量一轮（沉没）+ 1,389 复训；对比组 FULL = 全量一轮 + 全量复训。省的是"第二轮及以后"，不是"从零开始"。论文标题"Less is More for RL Scaling"的算力叙事里，第一轮的 8k RL 成本是被隐藏的前提——做预算时必须把"轨迹库"当成一次性基建成本摊销（见 §5 的 flywheel 节奏设计）。
2. **"随大流"偏见：平均轨迹参照会系统性漏掉特立独行的关键题。** $s_i$ 奖励"像平均"，惩罚偏离。但某类推理能力可能只由少数几道"轨迹特异"的题解锁（比如唯一需要长程回溯的题，它的 $r_i^k$ 长期 near-zero 后突然跃升——形状不像平均对数曲线， $s_i$ 低，被筛掉）。论文没有分析被筛掉的 7,134 题里有没有"少数派关键题"；LINEAR 对照只证明了"比线性假设好"，没证明"平均参照"是最优参照。这是 LIM 相对 LESS 的结构性弱点：LESS 的 target 锚点至少是**任务显式指定**的，LIM 的参照是**数据驱动的平均**——平均会被多数题绑架。
3. **奖励只有三档，不看过程。** $r_i^k\in\{1,-0.5,-1\}$ 只认"答案对+格式对"。数学题里"答案蒙对但推理过程是错的"题，轨迹看起来和"真学会"一样（都是 1），会被同等选中。选出的 1,389 可能富集"答案碰对"的题——这是 R1 用更严格可验证奖励 + 过程监督要解决的问题，LIMR 论文没有做过程质量的审计。
4. **"Base 起始"的表述水分。** Table 1 写 Init Model = Base，但 Qwen2.5-Math-7B 是数学域预训练过的模型。真正的"从零 RL"（R1-zero 用的是通用 base）起点更脏、轨迹噪声更大，LIM 在那种起点下是否还筛得准，论文没验证。结论的外推边界：数学推理 + 7B + 数学预训练起点。
5. **阈值 $\theta=0.6$ 是调出来的。** 论文没有给出 $\theta$ 的敏感度分析（0.5/0.7 会怎样），也没有 principled 的选择方法；LINEAR 用 $\theta=0.7$ 得到 1,138 题——两个方法的题数都不一样，Table 2 的对比里"方法"和"题数"两个变量是混在一起的。严格说，LIMR > LINEAR 的结论里有一部分可能是"1,389 > 1,138"的题数效应。
6. **证据没证明什么**：只测了数学三榜（AIME24/MATH500/AMC23），**没测通用能力的"定向税"**（为数学精选是否伤了通用指令跟随——与 LESS §4.5 的缺口同构）；没对比"1,389 LIM 题 + 随机 7k"混合（无法区分"去掉噪声"和"选中精华"的贡献）；没在 32B+ 或代码域复现；LIMO/s1 在 7B SFT 拉胯的真正原因是"32B teacher 长 CoT 超出 7B 容量"——§3.3 的"RL > SFT for small models"结论在 32B 规模下未必成立（LIMO/s1 本来就是 32B 的 SOTA 路线），不能引申为"RL 永远优于 SFT"。

### 5. 迁移到 coding / post-training data

**可执行实验 — coding 池的"轨迹对齐 RL 筛选"（3–4 周可跑，含一轮沉没成本）**

1. **第一轮（沉没成本，轨迹基建）**：用 Qwen2.5-Coder-7B（或内部 code base）在 50k coding RL 池上跑一轮 GRPO/PPO。奖励照抄 LIMR §2.4 的三档，但把"答案正确"换成 coding 的白盒定义：全过 hidden unit tests = 1；可运行但测试失败 = -0.5；编译失败/格式错 = -1。每题记录每 epoch 的 pass@1 均值作为 $r_i^k$ 。
2. **LIM 筛选**：算平均轨迹 $r_{\text{avg}}^k$ ，用 LIM 公式打分， $\theta$ 按保留 15–20% 调（对标论文 1,389/8,523≈16%）。**coding 特有修正**：LIMR 的"答案对"在数学里可能是蒙对，在 coding 里必须用 hidden tests 堵住——把 1 档定义为"全过 held-out tests"而非"输出文本匹配"，这是论文没做、coding 必须加的。
3. **复训对照**：三组——LIM 子集、全量、随机同尺寸子集，在 LiveCodeBench / HumanEval+ 上比 pass@k，并记录 MMLU 看定向税（补论文 §4.6 的缺口）。
4. **成本纪律（针对 §4.1 的后验成本）**：把第一轮全量轨迹定为"季度基建"——每季度跑一次全量产出 LIM 库，季度内的所有迭代（超参、奖励塑形、课程调整）都只用 LIM 子集复训。用 Fig 3b/3c 的发现指导 rollout 分配：轨迹 near-zero 的题直接从采样池降权（它们是长度抖动的主要来源），把 rollout 预算让给 $s_i$ 高的题。
5. **与 LESS 的分工**：训练前的冷启动配比用 LESS（静态、便宜、先验）；第一轮 RL 跑完后，用 LIM 决定"第二轮训什么"。两个判据串起来，正好覆盖"训练前→训练中→复训"的全周期。

### 6. 今天的一道思考题

综合 **Day11 LIMR、Day04 LESS、Day28 Open-Reasoner-Zero**（答案不在任何一篇原文里）：

**(a) 给 LIM 造一个"先验版"。** LIM 是后验的（§4.1：必须先跑完一轮全量 RL 才有 $r_i^k$ ）。假设你付不起第一轮全量成本，设计两种**训练前可算**的 proxy 来估计某题的"可学习性"（即预测它的 $r_i^k$ 轨迹形状）：
- Proxy 1：用 SFT-warmup 后的模型对每题采样 $K_0$ 个响应，算 pass@k，用"pass@k 随采样温度/轮次的变化斜率"当可学习性代理。
- Proxy 2：用小 proxy 模型（如 1B）跑**短轨迹**（总 epoch 的 10%），把短轨迹外推成长轨迹的形状分类（near-zero / 快涨 / 慢涨）。
对每种 proxy，明确写出它的计算式，并论证它会**系统性漏掉哪类题**（提示：想想 LIM 分母里"理想轨迹恒为 1"的含义——先验估计最大的盲区，是"模型在训练中后期才解锁的新能力"，即轨迹出现**拐点**的题；两种 proxy 对拐点的盲视程度有何不同？再用 LESS 的语言回答：这两种 proxy 分别对应"目标梯度"的哪种近似，它们的近似误差来源是什么？）。

**讨论（2026-09-11）**

*(i) LIM 公式的数学基础（§3(a) 的补完）。*

符号： $i=1,\dots,N$ （ $N=8523$ ）； $k=1,\dots,K$ （epoch）； $r_i^k\in[-1,1]$ 为第 $i$ 题第 $k$ 个 epoch 的平均奖励（每 prompt 8 条 rollout、三档 $\{1,-0.5,-1\}$ 的均值——Monte Carlo 近似）；轨迹视为 $\mathbb{R}^K$ 中的向量 $\mathbf{r}_i$ 。

反事实问题：Day02 回答"删掉这题，终点 loss 变多少"（要 $H^{-1}$ ）；Day03 回答"这题在训练轨迹上贡献了多少梯度对齐"（要每步梯度）；LIM 回答行为层面的问题——"这题的奖励轨迹长得像不像'正在被学会'的样子"，用形状相似代替因果贡献。

推导：参照系取群体平均轨迹 $\bar{\mathbf{r}}$ ；分子 $\|\mathbf{r}_i-\bar{\mathbf{r}}\|^2$ 量偏离；分母 $\|\mathbf{1}-\bar{\mathbf{r}}\|^2$ 量整轮学习的 headroom（平均轨迹到完美轨迹 $\mathbf{1}$ 的距离）。分母对全 run 为常数，故同一轮内按 $s_i$ 排序等价于按分子排序；分母只给阈值 $\theta$ 绝对含义。等价变形（恒等式）： $s_i>0.6\iff\|\mathbf{r}_i-\bar{\mathbf{r}}\|<\sqrt{0.4}\,\|\mathbf{1}-\bar{\mathbf{r}}\|$ ——以平均轨迹为球心、半径正比于 headroom 的 $K$ 维球，球内留下。

几何： $\mathbf{r}_i=\mathbf{1}\Rightarrow s_i=0$ （恒等式：已学会的题得零分）； $\mathbf{r}_i=\bar{\mathbf{r}}\Rightarrow s_i=1$ ，且 $s_i\le1$ 恒成立；轨迹贴着最低奖励档（ $r_i^k\approx-1$ ）的题， $s_i$ 显著为负。代数形式即统计的 $R^2=1-SS_{\text{res}}/SS_{\text{tot}}$ ：分子是"用平均轨迹预测该题"的残差，分母是"用完美轨迹预测"的残差（此为解读，非论文原话）。

连接：Day02→Day03→Day05→LIM 是"成本递减、因果性递减"链： $H^{-1}$ → 梯度点积 → damped Fisher → 只用 rollout reward。LIM 分数是训练的副产品，零额外成本。

区分三类陈述：恒等式—— $r_{\text{avg}}^k$ 定义、 $s_i\le1$ 、选球等价变形；近似——8-rollout 均值、"对齐 $\approx$ 价值"（相关性代因果）；heuristic—— $\theta=0.6$ 无敏感度分析、分母取 $\mathbf{1}$ 而非轨迹方差（让 $s_i=0$ 对应"已学会"是漂亮但非强制的选择）、三档奖励数值是 shaping： $-1\to-0.5$ 先教格式、 $-0.5\to1$ 再教正确，负奖励把早期 $r_{\text{avg}}^k$ 压到 0 以下、放大分母 headroom。

*(ii) Proxy 1 的数学实质。*

pass@k 直接当代理 = 只用 $k=0$ 处单点值 $r_i^0$ 代替整条曲线： $r_i^0\approx1$ 扔掉（太简单）， $r_i^0\approx0$ 保留。但"永远学不会"与"后面才开窍"在 $k=0$ 处长得一模一样——proxy1 不是错，是**不可识别**：单点数据原则上区分不了这两类。这是零阶代理（只看位置），动机是引出 proxy2 的一阶信息（形状）。

*(iii) Proxy 2 形状分类的完整推导。*

反事实问题：只看前 $K_0\ll K$ 个 epoch 的探测窗口，预测整条轨迹形状。参数族（近似）： $\mu_i(k;c_i,\alpha_i,\tau_i)=c_i\cdot\sigma(\alpha_i(k-\tau_i))$ ， $\sigma$ 为 logistic； $c_i\in[0,1]$ 可学上限， $\alpha_i>0$ 上升速率， $\tau_i$ 解锁时刻（拐点 epoch）。拟合： $(\hat{c}_i,\hat{\alpha}_i,\hat{\tau}_i)=\arg\min\sum_{k=1}^{K_0}(r_i^k-\mu_i(k))^2$ 。分类（阈值 $\delta_c,\tau^*$ 为 heuristic）：near-zero（ $\hat{c}_i<\delta_c$ ）、快涨（ $\hat{c}_i\ge\delta_c,\hat{\tau}_i\le K_0$ ）、慢涨（ $\hat{c}_i\ge\delta_c,\hat{\tau}_i>K_0$ ——LIM 想保留的正是这类）。外推：用拟合曲线补全 $K_0+1..K$ ，连同 $\hat{r}_{\text{avg}}^k$ 代入 LIM 公式得 $\hat{s}_i$ （两层近似：曲线族 + 群体平均外推）。

*(iv) 盲区：proxy2 系统性漏掉慢涨题。*

探测窗口全零时， $(c_i\approx0,\text{任意 }\tau_i)$ 与 $(c_i>0,\tau_i\gg K_0)$ 的 probe 似然几乎相同——**不可识别**。Fisher 信息 $I(\tau_i)$ 在 $\tau_i$ 远离窗口时趋于 0 ；任何点估计都必须靠先验打破平局，而"全零题是真不行还是大器晚成"的先验正是没有的。第二层盲区：sigmoid 族本身可能错——能力跃迁若是突变式（phase transition / grokking）， $\tau_i$ 对早期数据是信息论意义上的零信息。呼应 §4.2：proxy2 把"漏掉后来解锁题"从后验搬到了先验，但没有解决。串联：proxy1 是零阶（位置），proxy2 是一阶（形状），都被"未来解锁事件对过去数据的不可识别性"卡住——这正是 Day02/03"数据价值随时间变化"的回声。

**(b) 把 LIM 从静态改成在线。** Open-Reasoner-Zero 用动态采样（在线难度分层）替代了 LIM 的" $\theta=0.6$ 一次性选定"。回答：
- ① 静态 LIM 集在训练中期的结构性问题： $r_{\text{avg}}^k$ 是**历史**平均轨迹；当模型在第 $k_0$ 个 epoch 发生能力跃迁（如突然学会长程回溯）， $r_{\text{avg}}^k$ 的形状本身变了——此时用旧 $s_i$ 筛出的集会出现什么偏差（提示：跃迁前"太难"的题，跃迁后可能正好进入最近发展区，但它们的旧 $s_i$ 是低的）？
- ② 设计"在线 LIM"：每 $T$ 个 step 重算一次 $s_i$ （用滑动窗口的最近 $W$ 个 epoch 重算 $r_{\text{avg}}^k$ ），给出**淘汰规则**（ $s_i$ 跌破 $\theta_{\text{drop}}$ 则移出采样池）和**补入规则**（从被筛掉的 7,134 题里按新区间的 $s_i$ 补回 $\theta_{\text{add}}$ 以上的）。 $\theta_{\text{drop}}$ 和 $\theta_{\text{add}}$ 应该相等吗？为什么（提示：想想迟滞比较器 hysteresis——频繁换入换出对 PPO 的 KL 约束意味着什么）？
- ③ 用 Fig 3b（LIMR 长度先降后升 vs FULL 不稳定）论证：在线 LIM 省下的 rollout 主要来自哪类题？给出"省量"的估算式（用 $N$ 、 $s_i$ 分布、每题 rollout 成本 $c$ 表达）。

**讨论（2026-09-11）**

*① 旧 $s_i$ 集合的双向偏差。*

$s_i$ 是在 $\pi_{\text{old}}$ （筛选轮的策略）下算的，记 $s_i(\pi)$ 。能力跃迁后反事实轨迹改变，偏差双向：上端——对 $\pi_{\text{old}}$ 是 frontier 的题，对 $\pi_{\text{new}}$ 已 trivial，集合整体偏易，reward 方差与非零 advantage 被稀释；下端——对 $\pi_{\text{old}}$ 全零被扔掉的题里，对 $\pi_{\text{new}}$ 可解锁的部分被永久排除。更深一层：参照系 $r_{\text{avg}}^k$ 本身是旧 run 的群体平均，新模型下整体上移，"与平均轨迹对齐"的相对标准整个变了——偏差不只是"题变简单"，而是**坐标系变了**。这是 offline 选择的分布偏移，也是 Day02"同一数据的价值随 target 变化"的回声。在线 LIM 的动机正在这里：分数必须跟着模型一起长。

*② $\theta_{\text{drop}}$ 与 $\theta_{\text{add}}$ （2026-09-11 修订：原"调高 $\theta_{\text{drop}}$ 做偏差修正"版有误，见下）。*

标准 hysteresis 要求 $\theta_{\text{drop}}<\theta_{\text{add}}$ （Schmitt trigger，死区防抖）。原先"rolling 滞后→调高 $\theta_{\text{drop}}$ 抵消上偏"的推理有一个根本缺陷：滞后偏差是**每题不同**的。设第 $i$ 题真实可学性以斜率 $m_i$ 衰减，窗口 $W$ 的均值估计偏差为 $b_i\approx m_i\cdot W/2$ ——方向恒为正（衰减期窗口均值恒大于当前值，这是数学），但大小取决于该题自己的衰减斜率。统一上移 $\theta_{\text{drop}}$ 等于假设所有题的 $b_i$ 相等：慢衰减的题（ $b_i$ 小）在还可学时就被提前踢掉（false drop），断崖题（ $b_i$ 大）则修正不足、照样晚踢。方向修对了，大小一刀切，专伤还有残余学习信号的慢衰减题。

反过来，" $\theta_{\text{drop}}$ 取低更 robust"是在 $b_i$ 未知时拒绝做没把握的修正（minimax 意义下 robust），代价是把"方向已知"的免费信息也扔掉、所有衰减题系统性晚踢。决策论对"方向已知、大小未知"的标准答案是**衰减修正**：方向照修但只修一小部分；更干净的是把修正从阈值搬到 estimator——缩短 $W$ 、给 recent epoch 加权，让 $b_i$ 自己变小。**滞后是估计问题，不是判决问题**。最终处方： $\theta_{\text{drop}}$ 取低（保死区、防抖、零误伤），滞后用 estimator 修；硬要动阈值，最多小幅上移并明说代价（用少量 false drop 换 timeliness）。

关于"避免频繁出入"：PPO 本来就吃非平稳数据，换题不影响收敛——hysteresis 不是为 PPO 稳定性准备的，而是防两种纯浪费：其一，同一题在阈值附近反复"入选攒 rolling 统计→淘汰清零"，一次横跳废掉一个窗口的预热成本；其二，让课程分布变化平滑、可诊断。纯收敛角度，确实可以不要。

*③ Fig 3b = Response Length。*

Fig 3b 画的是训练过程中平均响应长度曲线。原文 §3.2：MATH-FULL 的长度曲线不稳定，LIMR 的先降后升。长度是"推理努力程度"的代理：先降 = 砍掉冗余废话；后升 = 在精选难题上把推理链真正做长。FULL 的抖动说明全量数据难度混杂、噪声大，模型在"变长变短"间摇摆。这是 LIM 有效的旁证（精选集让训练动态更干净），但注意：这是过程侧的间接证据——三档 outcome reward 本身不审计推理过程（§4.3 边界）。

7. **初读 "+16.7% AIME24" 的参照系纠正**：初读 NOTES 写"小样本 RL 泛化更好：AIME24 +16.7%"，易被误读为相对全量 RL 的提升。原文（Abstract / §3.3 / Table 3）的参照系是 **LIMO / s1 的数据在 7B 上做 SFT 的基线**（15.8）—— $32.5-15.8=16.7$ 是百分点差；而相对**全量 RL**（32.5），LIMR 在 AIME24 上是**持平**，超出的两项是 MATH500（ $78.0-76.6=1.4$ ）和 AMC23（ $63.8-61.9=1.9$ ）。"少即是多"的准确表述是"16% 数据量达到全量水平"，不是"全面碾压全量"。
