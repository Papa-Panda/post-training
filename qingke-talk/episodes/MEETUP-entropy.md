## 一句话总结

雨辰把开源 LLM 的 RL 为什么 scale 不起来归因于 entropy collapse，并给出三件套证据与解法：先用一个含可解释参数的经验函数证明「不加干预的 RL 只是在拿熵换性能、上限在训练前就已注定且可预测」；再从 softmax policy 的一步更新推导出熵的变化正比于 token 处 log-probability 与 advantage 的协方差，定位出真正吃掉熵的是协方差最大的极少数离群 token；最后对这批 token 做随机 detach（Clip-Cov）或加一大系数 KL 惩罚（KL-Cov），在不牺牲稳定性的前提下让熵不再塌陷、性能继续上涨，且模型越大收益越大。

## 核心

### 背景：开源 RL 的「几百步就饱和」问题

讲者先立问题：RL 在 AlphaGo、o1、DeepSeek-R1 上已被证明能推动推理能力，但开源社区（Qwen、Llama 系列）没法像预训练那样把 RL 连训几个月持续涨点——大多几百步性能就饱和。讲者团队认为头号阻碍是 entropy collapse：以普通 GRPO 训练为例，policy entropy 掉得极快，约 800 个 gradient step 就消耗掉 94%（字幕）；当熵只剩 6% 时，性能的提升也已完成了其总提升量的约 93%（字幕）——熵耗尽之后，性能再也涨不动。他还呼应了清华那篇 pass@k 的工作：大 k 下 RL 后模型与 base model 差不多，RL 像只是在激发 base model 已有的 latent behavior。

### 经验规律：熵与性能之间有一条可预测的「兑换曲线」

讲者团队在 Qwen、Llama、DeepSeek 等多个模型上广泛实验，发现 entropy 与 performance 强相关，并拟合出一个经验函数：以 ， $R$ ， 记性能、 ， $H$ ， 记熵，函数含两个有物理意义的参数—— ， $\beta$ ， 是熵耗尽时下游任务性能的上限， ， $\alpha$ ， 决定把熵兑换成性能的速率（字幕口径；函数确切形式字幕未逐字给出）。三条性质：

1. **可事前预测**：只用训练前 36 步（字幕原话「前 36 个 road step」，单位待核）的数据拟合该函数，即可预测后续整个训练动态，平均 RMSE 约 0.9%–1.2%（字幕）。
2. **算法与数据无关**：GRPO、PRIME、REINFORCE++（字幕识别为「R 加加」，即同场 OpenRLHF 分享提到的 REINFORCE++）都符合；不同训练数据（字幕识别含「double max」「森 8K」及 PRIME 的难度分级数据，疑为 DAPO-Math、GSM8K 等，待核）也都符合。
3. **跨规模可外推**： ， $\alpha$ ， 与 ， $\beta$ ， 在不同 model size 之间呈 log-linear 关系，意味着只训小模型就能预测大模型的性能上限。

结论很悲观：不加干预时，RL 的天花板在训练前就被预先决定了——「你的熵能消耗多少、性能能提高多少」都是有迹可循的，这正是要打破的「诅咒」。

### 机制：每步熵变正比于 log-prob 与 advantage 的协方差

为找干预点，讲者对 softmax policy 做了一步更新的理论推导（细节跳过，结论对 policy gradient 与 natural policy gradient 都成立）：每个 token 处的熵变化，正比于该处动作 log-probability 与 advantage 的协方差（笔者按讲者口述整理）：

$$\Delta H \propto \mathrm{Cov}(\log \pi(a), A(a))$$

直觉分四种情形：高概率动作拿到高 advantage（协方差为正且大）→ 模型快速收敛到已知的次优解，熵被消耗；低概率动作偶然拿到高 advantage（两者反向）→ 熵上升、促进探索；低概率动作拿到很低的 advantage → 探索被重罚，同样压熵；高低错位时熵升。实测中该协方差整体均值很小但持续为正，与熵差分曲线趋势几乎一致——这解释了为什么正常训练里熵会被持续单向消耗。

关键放大镜在 token 级分布：协方差的全局均值只有约 0.003（字幕），但 top 万分之二（0.02%）的 token，其协方差均值是全体均值的几百倍甚至几千倍（字幕）。这些离群 token 才是 entropy collapse 的「最大罪魁祸首」——干预应该只动它们。

### 两条常规解法为何失效

- **Entropy loss 正则**：系数极其敏感，0.0001–0.001 看着还行，调到 0.005 或 0.01 熵就直接「飞掉」（字幕）；而且即便熵被抬高，性能也不涨——抬熵本身不等于涨点。
- **Reference KL 惩罚**（RLHF 常用）：0.01、0.05 等系数下熵看似健康，但仍未摆脱「拿熵换性能」的曲线——最高的熵那条线恰恰性能最低，本质还是在同一条兑换曲线上滑动。

### 方法：只干预高协方差 token 的 Clip-Cov 与 KL-Cov

两种方法都衍生自 PPO 的两类变体（clip 系与 KL 系），共同思想是只降低极少数高协方差 token 在更新中的权重：

1. **Clip-Cov**：朴素做法是把高协方差 token 在全局直接 clip 掉不更新，但实验发现训练前期有效、随后带来不稳定性。为此引入随机性：在一个仍然很离群的协方差 band 内（字幕给的量级为 1–5，相对均值 0.003 而言极高；确切定义待核）随机挑选一部分 token，在 update 时 detach 掉。
2. **KL-Cov**（讲者更偏好、更稳定）：挑出协方差最大的 top-k token，对它们额外加一个系数非常大的 KL 惩罚——soft 的乘性约束，兼顾稳定性。

定位为「以最低成本干预」：不动绝大多数正常 token，只摁住离群者。讲者顺带提到，字节 DAPO 的 clip-higher（把 clip 区间从 0.8–1.2 放宽到 0.8–1.28）之所以有效，正是因为它顺带捞回了一批「低概率、高 advantage」的 token，与这里的机制分析互相印证。

### 结果：熵不塌、性能继续涨，越大越灵

- 用两种方法调 clip 阈值或 KL 系数，都能把 entropy 稳定控制住、不再 collapse；response 指标（讲者称可粗略反映模型是否在探索新的 policy/pattern）不降反略升。
- 性能（字幕口径）：32B 模型在 AIME 上绝对值提高约 15 个点，average 提高约 7 点几；且 32B 上的收益明显高于 7B——更大的基座探索空间更大，打破熵天花板后释放的上限也更高，这反过来验证了方法的作用点。
- 落地：KL-Cov 已用于上海 AI Lab Intern-S1 的训练，讲者称比普通 GRPO 类方法有明显提升（字幕口径，未给数字）。

讲者的收尾观点：现在很多 RL 方法只是在提高模型的 self-confidence——更稳定、更不探索，熵低到对训练数据近乎确定性输出；训出「更大但分布更窄」的模型是不是好事尚无定论，但至少熵这条线现在有了可测量、可干预的抓手。

## 可迁移

- **把熵当一等公民监控量**：训 RL 时除 reward 外同步画 policy entropy 曲线，并用「前几十步拟合熵-性能兑换曲线」做廉价的天花板预测——几十步就能估计这轮训练值不值得继续烧卡，比跑满再看曲线省得多（注意该规律字幕口径未与论文核对）。
- **token 级协方差诊断**：与其全参数加 entropy bonus，不如先统计每个 token 的 ， $\mathrm{Cov}(\log \pi(a), A(a))$ ， 分布，看塌陷是不是由极少数离群 token 驱动；若是，只对 top-k 做 detach 或大系数 KL，是改动面极小的干预（GRPO/PPO 代码里几行）。
- **给 clip-higher 一个机制解释**：调 clip 上界时可以同步观察被捞回的低概率高 advantage token 占比，用它判断放宽是否在做「捞探索 token」而非单纯放大更新步长。

> 「它本身就只是在拿这个 entropy 去换 performance。也就是说我的 entropy 耗尽了，我的 performance 也就没有办法继续上涨，也就是没有办法很好的去 scale up。」
