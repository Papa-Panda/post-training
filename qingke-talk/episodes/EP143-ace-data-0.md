## 一句话总结

具身智能缺的不是模型而是数据：现有数据集要么模态碎片化（只有第一视角视频、没有真值运动与接触），要么在实验室里录、任务只有几秒长。NTU S-Lab 与大晓机器人把真实家居改造成「环境式采集棚」ACE—— 桌面级与房间级两套配置同步录第一视角与多视角视频、全身与手部运动、物体 6-DoF 轨迹、音频与触觉，攒出 ACE-Data-0：150 小时、17M 帧、75,000 个交互 episode、200 类任务、50 名参与者；再配一套从「信号 → 组件 → 交互」三级递进的基准，实测 30 多个现有方法在接触、遮挡、自运动与长时程下集体掉档—— 数据引擎本身，就是这一期的主角。

## 核心

1. **背景/问题**：论文把具身数据的困境说得很直白：语言/视觉模型站在人类几百年攒下的档案上，物理技能（手怎么握杯、用多大力拿玻璃）从来没被写下来过，所以具身数据「必须被建造而非被发现」。而现有数据集三头都缺一截：（一）模态碎片化—— Ego-Exo4D、EPIC-Kitchens 这类大规模第一视角集没有真值的身体/物体运动与同步第三视角；BEHAVE、GRAB、ARCTIC 这类动捕集有精确姿态却没有第一视角，音频与触觉几乎全员缺席；（二）环境不自然—— 带物理标注的数据集清一色实验室棚拍，没有真实家居的遮挡、空间约束与物体多样性；（三）时程太短—— 绝大多数 HOI 片段只有几秒、一个简单动作，而真实家务是分钟到小时级、目标导向、跨房间串联子任务。结论：完整的「感知—动作」闭环从来没被任何数据集同步观测全过。
2. **方法/设计（采集系统 ACE）**：思路是把真实家居环境本身仪表化成录音棚，分两套互补配置：**桌面级**（密集近距相机 + 高分辨率触觉，抠手-物精细操作）与**房间级**（传感器铺满整个带家具的家居空间，录全身运动、位移与全屋尺度的交互）。每个 take 同步打包：第一视角（四个鱼眼视角 + IMU + 逐帧 6-DoF 头显位姿）、多视角第三视角视频（桌面级手部真值由 8 台同步外视角相机三角化 + 人工精修，房间级用 Manus 动捕手套）、41 关节全身骨骼与铰接手部姿态（转 SMPL-X 参数）、物体 6-DoF 轨迹（物体预先扫描或以 2DGS 重建网格，50 余个实例）、多通道音频、触觉手套的掌形压力网格（做了标定归一化与基线校正）。同步靠光学时钟把所有流对齐到动捕时钟（毫秒级精度），标定靠 marker 桥接把固定相机与穿戴相机注册到同一世界系。采集时只给目标级（goal-level）指令、不给分步脚本，让参与者按自己的方式规划、犹豫、即兴—— 保住自然行为差异，但量测精度不因此打折（每个时刻有 8 个以上视角同时观测，并锚定在度量级身体/手部/物体状态上）。标注五类（物体、身体、手部、触觉、音频+语言），且大比例由追踪到的物理状态自动导出而非靠估计管线：每帧的手/身体 3D 状态会被重投影到每个相机的每一帧上做像素对齐的 2D 标注，在家具遮挡、极端视角、运动模糊下仍正确—— 这是「真值来自量测而非检测」的核心卖点。
3. **实验/实战（三级基准）**：基准沿感知链自下而上搭三级，恰对应具身 agent 必须串起来的三件事：感知接触、估计场景状态、掌握手-物交互。**第一级（低层信号）：由视觉推触觉**—— 给第一视角视频预测全手压力分布，对触觉手套真值打分。三法里 TouchAnything 最好（时间准确率 0.7095、C-IoU 0.1646、V-IoU 0.1357、压力中心误差 CoP 6.58），但绝对值仍低；PressureVision 几乎交白卷（C-IoU 0.0007、V-IoU 0.0000）；结论是「判断有没有接触容易、恢复压力分布在哪里难」，尤其手-物互相遮挡时。**第二级（场景组件）：人体运动估计**—— 拿动捕真值当尺：单视角第三视角最好的是 SMPLest-X（PA-MPJPE 55.7 mm / MPJPE 58.8 mm）；第一视角方法整体差一个量级（EgoAllo MPJPE 147.9 mm、EgoEgo 163.4 mm），世界系对齐误差 WA-MPJPE 最好的单目方法也有 180.2 mm（Human3R）—— 在真实家居里，现有姿态估计离可用还远，家具挡下半身、蹲柜子、够高处、躺沙发这些日常姿态都不在它们的舒适区。**第三级（交互）：手-物交互中的手部运动**，第一/第三视角同场对比（同一批 take、同一真值）：第一视角逐帧法 WildHands 关节精度最好（PA-MPJPE 11.2 mm），但世界系轨迹误差高达 98.2–102.1 mm（Dyn-HaMR / HaWoR）；第三视角 WiLoR 拿到 PA-MPJPE 9.1 mm、F@5 0.313，视频法 HaPTIC 的轨迹误差只有 63.0 mm。论文的判读很明确：**egomotion（自我运动）估计是第一视角手部重建的主要误差源**—— 不是手指关节估不准，是头一动、世界系就漂；两种视角各有各的死法（第一视角怕截断/畸变/模糊，第三视角怕身体与物体遮挡），融合与给 ego 方法喂量测到的头显运动是下一步。
4. **结论/观点**（论文口径，非讲者原话）：作者认为现有方法在接触、遮挡与长时活动下的退化，恰说明真实家居与受控实验室是两个难度世界；数据集的价值不止评测—— 因为 ego 视频、多视角视频、运动轨迹与接触监督全部同钟同步，「每个训练信号都指向同一个物理时刻」，这正是模仿学习、世界模型、VLA 需要的对齐方式。自陈局限：只有 2 个场地，布局/陈设/光照多样性有限；真值只覆盖仪表化实体（物体要预先扫描装 marker），铰接机构、流体、可变形材料的状态变化没有标注；动捕服、手套、头显与 marker 在画面里可见，可能引入数据集特有的视觉线索（模型可能学到「看到手套=在操作」的捷径）。伦理上参与者均为知情同意并授权公开发布。

## 可迁移（放到 RL 训练 / 数据构造 / 评测框架）

- **把「同步性」当数据资产的第一属性**：ACE 的核心工程不是相机多，而是所有模态同一时钟、同一世界系，且标注尽量从量测状态自动导出而非靠事后估计模型。迁移到任何多源数据管线（合成轨迹 + 真机日志 + 人类视频混训）：先统一时间戳与坐标系、能从状态自动打的标签就别用模型猜——标签的生成方式决定数据上限。RL 侧同理：rollout、reward、环境状态若不对齐到同一时刻，后面再强的算法也在学错位拼接的信号。
- **评测分级搭台子**：信号（接触）→ 组件（状态估计）→ 交互（完整行为）的三级基准，把「整链失败」拆成「哪一级先坏」。这套分层评测可直接搬到 agent 评测：工具调用对不对（信号）、中间状态恢复得准不准（组件）、长程任务成不成（交互），而不是只看最终成功率一个数；ego 手部轨迹的教训也提醒：先查漂移/对齐这类系统性误差源，再怪模型能力。
- **目标级指令 + 保留自然差异**：只给 goal 不给分步脚本，保住行为多样性（规划、犹豫、即兴），量测精度靠环境仪表化兜底。对应到 SFT/RL 数据构造：与其把轨迹清洗成千篇一律的「标准解法」，不如在标注质量上加固（自动真值、同步对齐），把多样性留给模型——后训练里过窄的数据分布同样会教出脆的策略。
- **标注自动化率决定数据集能否 scale**：「大比例标注由追踪状态自动导出」是 75,000 episode 规模的前提。任何想扩十倍的数据项目，先问哪类标注还能从系统状态（仿真器状态、工具调用日志、单元测试结果）免费导出，别把人力标在机器能算的地方。
