2一句话总结

四个背景互补的嘉宾（RL Infra、RL 后训练、SLAM）在一件事上罕见地一致：VLA 作为「通用机器人策略」的任务定义没有悬念，真正的分歧只在实现路径——世界模型该以什么形式内化进 VLA、A（action）这个模态为什么还没被 scale 起来、以及真机 RL 的样本效率与安全探索怎么解；on 形态之争则收敛为「人形只是具身智能的一个 specific case，双臂轮式 / 轮足是近期更被看好的工作形态」。

3核心（按议题）

议题一：世界模型与 VLA 的关系——VLA 就是终局吗

  • 于超：VLA 是不是终局「没有什么悬念」——只要任务定义是 condition on language 与 vision、output action 的端到端通用策略，它就是最终路径；有争议的只是技术实现（基于视频 backbone 还是 VLM backbone）。对世界模型他持「内化论」：不同人对世界模型的定义完全不同（RL 的人想要神经网络 simulator，CV 的人想要帧级可控的 predictor），他不认为 VLA 与世界模型冲突，「在某种意义上 VLA 应该内化了一个世界模型」；backbone 之争上他倾向 VLM 路线仍然要走，因为语言是对世界的高度抽象、VLM 发展更快，视频先验可以以某种形式压进 VLM 里，而不必以视频 backbone 的形式出现。
  • 李浩然：先给世界模型分了两类——表征世界模型（如 LeCun 的 JEPA 系列、Dreamer 的 RSSM，心智世界模型量化程度还不高）与生成世界模型（simulator、三维生成、视频生成）。他的判断是：世界模型比 VLA「更高级」，因为 VLA 只需回答最优策略，世界模型要模拟所有动作产生的未来状态；但更高级不等于更容易得到，它对数据和训练难度的要求更高。VLA 终局论他同样乐观，但点出 VLA 迟迟没跑出 scaling law 的原因大概率在 A：V、L、VL、VA 各自都被验证过能 scale，唯独 A 的表达随动作空间、坐标系、本体不同而高度多样，A 的不确定性远大于语言。主持追问「A 只需少量数据 align 到 VL 空间」时，他回应：本体与动作空间固定时成立，做通用策略时 A 必然牵扯运动学等机器人本体问题，不再是纯对齐。
  • 王光明（从 SLAM 视角补刀）：他最初以为 VLA 就是「现成视觉语言模型后面加个 action」，这样太简单了；但若把 VLA 理解为任务定义（只看视觉、听指令、完成事情），那就是机器人最终形态、没有意见。他强调 VLA 内部要学的东西很多：只做重建，没看到的部分怎么办；只做表征，复杂任务的语言描述精度不够；只做生成也不够——重建、表征、生成三件事都得做。

议题二：世界模型冲击下，SLAM 死了吗

  • 焦健浩：SLAM 的本质不是「摄像头转一圈建点云」，而是融合多传感器信息、构建对三维环境的一致表达。从科研角度，传统几何 SLAM 确实很难再做过大厂（Meta 智能眼镜自带的 SLAM 已在多种工况下做得很好，且这是硬件、标定、软件耦合的系统工程）；但具身智能时代对 SLAM 的要求变了——机器人频繁与物理世界交互，需要的不只是几何，还要懂语义、懂物理特性、能把物体间关系组织起来，这种「既懂语义又懂物理的三维空间构建器」空间非常大。关于前馈几何模型（VGGT 等）是否让基于优化的方法落后，他的回答是：前馈网络负责出结果，优化负责兜底——闭环检测、位姿图优化、BA 通过残差计算告诉机器人「你这个估计有问题」，在不可控的真实环境里这是安全底线。
  • 王光明：用「丑小鸭定理」式的判断开场——说一个东西「做好了」必须看指标和看任务。把 SLAM 重新定义为「实时重建」（real-time reconstruction）：重建的对象可以是几何、颜色、物理性质乃至人对环境的理解，机器人显然都还没达到。他把重建、表征、生成看作三种思路：单图生成世界对传统 SLAM 是「夸张」的做法，但两者做的事在某种程度上相似（都是从部分观测反推世界）；渲染（如 3DGS、NeRF）是 3D 到 2D 的一种很好的投影 / 反推方式，但机器人操作还涉及触觉、力、本体结构，不能指望仅靠视觉解决全部问题。谈 scaling law 时他给出一个冷静的尺度论：自动驾驶的 VA 解空间比通用机器人小得多，所以在 VLA 上谈 scaling law 行不行，要么等算力再上几个台阶，要么靠模型与框架创新大幅压缩解空间。

议题三：真机 RL 怎么做——样本效率、安全探索与「第三条 scaling 路」

  • 李浩然：真机 RL 与仿真 RL 的两个根本区别是样本效率（真机忍受不了百万、上千万步）和安全性（探索对策略提升必不可少，但探索在真实世界产生不可预料的安全隐患）；外加两个常被忽视的问题：on-policy 方法在真机上难扩展、以及 VLA 框架下的持续学习（不能学新任务就忘旧任务）。现有真机 RL 工作分两类：一类无人工参与（把初始策略成功率先提得很高再真机微调，代价是交互成本高）；另一类是 human-in-the-loop，用得更多——人既能注入高质量数据急速提升样本效率，又能在机器人不安全时介入拉回安全区。他特别指出今年的一个认知更新：所谓高质量数据，不再是「动作规范、无多余动作」，而是能让机器人从失败中恢复的数据，从 DAgger 到 π0.6 都是这个思路。但他也坦承人环的尴尬：很多时候起作用的是人的数据而不是 RL 算法本身，所以下半年他们一直在挣扎着「把 human 拿掉」，从训练范式、奖励函数（稀疏奖励 vs 过程奖励 vs 学通用价值函数）、安全探索、持续学习四个方向尝试。
  • 于超：提出具身智能 scaling 的「第三条路」。前两条是数据 scaling（遥操数据、无本体人类数据）和模型 scaling（做到 B 级参数），但数字空间隐含的前提是算力和环境可以无限 scale，具身智能做不到；第三条路是真机数量的 scaling：多台真机并行学不同任务，可以大幅缓解持续学习（不再对着单个环境 overfit 一个 task），而人环在他这里不是要去掉的东西——物理世界不可加速，人环是提升数据效率的手段；学术界觉得人力贵（学生不愿 24 小时盯机器人），但对创业公司和大厂，人环反而是在解决劳动力问题、且当前人比机器便宜（机器维修、售后、时间成本都高）。真机并行规模的边界他说还没摸到，自估会到「百的级别」，明年 2 月希望能给出答案。被问到 RL infra 与传统平台的区别，他给出 RLinf 的口号：「像使用 GPU 一样使用你的机器人」——把机器人看作灵活可配置的资源，以最简单的标准化接口接入世界上所有真实机器人、回收数据用 RL 学习，并坚持开源让研究平权。

议题四：人类数据与导航数据的 scaling

  • 焦健浩：导航场景里真机数据仍不可替代（社交导航必须与真实的人互动才能拿到有价值的数据），由此引出「终身导航」问题：机器人在不断变化的环境中持续知道自己在哪、持续更新对环境的认知，传感器数据以 stream 形式不断回流到中央服务器训练模型。数据源可以众包：Meta / 小米的智能眼镜（自带摄像头与 SLAM）、机器人本体、AR/VR 眼镜、以及人手一部手机——类比特斯拉车队采数据。但脏数据如何清洗是核心课题。
  • 主持陈星宇补充：他前两天刚刷到一篇论文，不只用手机，还用手表、耳机记录人整天的生活状态，作为机器人学习的样本。
  • 王光明：前馈模型（如 VGGT 一类）之后加优化保底是合理组合，前馈模型能提供纯几何做不好的语义与物体间理解；但泛化的根本难题不变——深度学习模型总会遇到分布外的 corner case，只能尽量扩大训练数据、靠 human-in-the-loop 提数据质量、在越来越多的任务上把指标做上去。

议题五：本体形态之争——人形是终极形态吗

四位出奇地收敛，本场分歧最小的一节：

  • 李浩然：先立论「智能与形态有没有关系」——按具身智能的核心定义，智能在与环境的交互中产生，能接触的环境多样性决定智能上限；若终极目标是 AGI，需要一个能做 AGI 任务的本体，人形是很好的算法验证试验场，但不一定是高效的工作机器人形态，社会分工细化后按场景做形态异化同样符合进化逻辑。
  • 于超：2025 上半年争议还很大，下半年已收敛——人形是具身智能的一个 specific case 而非终极 case；当前更被认可的是双臂轮式，轮足在极端、危险条件下稳定性和适应性更好；只把「手」学明白都已很困难，腿完全可以解耦。除了表演，人形到底能赋能什么，质疑很多；后续人形赛事也会更注重上半身操作能力。
  • 焦健浩（机器狗背景）：轮足形态最有意思，兼有轮子的通行效率与跨越台阶、gap 的能力；野外救援这类任务四腿轮足在载重、续航、速度上全面胜过人形，「10 分钟救下一个人和 1 小时救下一个人」之间没有理由不用更高效的方案；但科研上仍应用更复杂、功能更强的平台做研究。
  • 王光明：补了一个形态智能的例子——剑桥做软体机器人的同行讲，猫去掉头之后腿还能跑一阵，说明智能不全在脑子里，也在肌肉、结构与形态里，「结构决定性质」；人是自然进化的产物，谁能保证人不是局部最优解？但他同样承认，我们的环境是为人设计的，人形有其意义，各行各业也需要其他形态。

2026 展望（收尾）

  • 王光明：关注 SLAM 重建与表征、生成的结合，以及这些东西怎么进入 VLA、怎么和 RL 结合。
  • 焦健浩：关注机器人的「海马体」——持续作业中不断更新且不轻易遗忘的记忆，从空间理解的记忆扩展到多模态记忆。
  • 于超：先把 RLinf 干完（至少一年），另外想看数据问题：RL 需要一个好起点，但目前还没有足够好的模型给 RL 当起点。
  • 李浩然：展望「具身智能体」——具身智能不是只有 VLA 和世界模型，SLAM、VLA、世界模型应混在一起协同发展成一个生态。

5共识与分歧

共识

  1. VLA 作为通用机器人策略的任务定义是终局，分歧只在实现路径（于超、李浩然、王光明三人明确表态一致）。
  2. 世界模型与 VLA 不是竞争关系：世界模型应内化进 VLA，或与之相辅相成（于超、李浩然）。
  3. 人形不是具身智能的终极形态：双臂轮式 / 轮足是近期更被看好的工作形态，人形更适合作为算法验证平台（四人一致，本场分歧最小的一节）。
  4. 高质量数据的定义已经更新：从「动作规范」变为「能让机器人从失败中恢复的数据」（李浩然提出，主持与于超讨论中呼应）。

分歧

  1. 世界模型该以何种形式进入 VLA：于超倾向 VLM backbone + 视频先验压入；李浩然认为生成式世界模型在能力上比 VLA 更高级、但更难获得；王光明主张重建、表征、生成三者都不可偏废。
  2. 人环的去留：李浩然在努力「把 human 拿掉」以凸显算法作用；于超认为物理世界不可加速、人环应长期保留，且应与工业界合作 scale 真机。
  3. A 是不是只需少量数据对齐：主持提出「A 只是 VL 空间的一个 align」的看法，李浩然认为只在本体固定时成立，通用策略下 A 的多样性是 VLA 没 scale 起来的主因。

6可迁移

  • 「像使用 GPU 一样使用机器人」的接口观（于超 / RLinf）：把异构真机抽象成可灵活配置、可回收数据的标准化资源，再在其上跑 RL——这与 RL infra 里把 GPU 集群抽象成 rollout / training 资源的思路同构，做具身 RL infra 时可直接借鉴其「标准化接口 + 开源平权」的组织方式。
  • 数据配方的认知更新（李浩然）：训练数据的「质量」应按能否让策略从失败中恢复来定义，而不是动作是否规范——迁移到 LLM / agent 的 RL 数据构造上，同样应优先收集带失败—恢复结构的轨迹，而不是只收干净的成功轨迹。
  • 前馈 + 优化兜底的系统设计（焦健浩）：让前馈模型出结果、用带残差的优化做安全校验，这一半步在任何「学习模型直接驱动执行」的系统里都适用，包括用学习型 verifier / reward 给 agent 轨迹兜底。

7疑问 / 下一步
