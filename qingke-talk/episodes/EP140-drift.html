2一句话总结

DRIFT 回答的问题是：在没有外部专家示范、只有可验证奖励时，模型如何从自己的轨迹里稳定地自我提升。讲者的判断是，GRPO 与自蒸馏（SDPO 一系）之争是伪问题，真正的缺口在于两者都不追踪「模型当前学会了多少」：DRIFT 用问题级难度路由（历史通过率）决定信号的种类与强度，用 token 级节奏门控把信用压到真正的推理转折点上，再用两阶段课程与跨批成功缓冲把正样本稀缺时的监督兜住。

3核心

问题定位：两条自提升路线共同的盲区

讲者先把背景收拢：让模型从自身轨迹学习有两条主流路线，一是 RLVR/GRPO，用组内相对奖励驱动探索；二是自蒸馏（字幕统一称 SDPO 一系，含 OPSD、SRPO、SDPO 等），用自身正确解等特权信息构造教师分布，提供稠密的 token 级监督。讲者特意澄清用词：他们强调「自蒸馏」而非经典 OPD，因为经典 OPD 的教师是更大且固定的外部模型，学生上限被教师锁死；自进化要的是教师与学生同体、协同变强。

两条路线共同的盲区是都不随模型当前能力自适应调整信号。GRPO 的三类信号错配被讲者逐一点名：

  1. 简单题过度优化：已掌握的问题仍被反复更新，产生大量冗余梯度，强化的往往只是格式与套话，而非抽象推理。
  2. 难题监督缺失：偶然 roll 出的正确轨迹有两种隐患，一是与当前能力相距太远的「天才轨迹」，学不到可泛化能力反而扰乱训练；二是过程全错但答案蒙对的轨迹（单选题场景下完全可能），拿去蒸馏等于系统性强化错误推理，是训练崩溃的根源之一。
  3. 边界题探索不足：中等难度、卡在能力边界附近的样本价值最高，却通常拿不到充分的学习信号。

外加一条工程性缺失：多数方法不保留也不复用跨 batch 的高质量正确解，每批辛苦踩到的成功轨迹用完即丢，形不成持久记忆。

方法总览：两级信号分配

DRIFT 被讲者概括为「两阶段、两级信号精炼」框架：问题级用难度路由分配蒸馏与 RL 信号，token 级用节奏门控细化 RL 更新，两阶段课程与成功缓冲负责把训练节奏和历史经验串起来。四个组件依次是：两阶段课程、难度路由（问题级）、节奏门控（token 级）、成功缓冲回放。

两阶段课程：先用便宜的自蒸馏爬坡

第一阶段（warm up）只用 SDPO，不用 GRPO，理由是成本：讲者给出字幕口径，在线策略蒸馏的训练开销远低于 RL（字幕原作「只需要 RL 大约 17 到 18 的训练开销」，按上下文应为分数口径，具体比例以论文为准），模型处于能力快速爬升期时用它高效拉升最划算。这一阶段选成功轨迹（success sibling）用「奖励优先、熵次之」的规则：在接近最高奖励的一批成功样本里选熵更高的那条，既保证正确性又在早期保留多样性，避免一上来就跟最确定的教师走、把探索空间压死。同时把成功轨迹提前写入全局 buffer，为第二阶段正样本稀缺时做准备。

第二阶段才启用难度路由与节奏门控，并按正确性分流信号，这是全场最核心的一处不对称设计：

  • 负样本走 SDPO。从 softmax 梯度形式看，GRPO 对负样本的更新只是把错误 token 的概率压低、再按原分布比例摊给其余 token，与正确解是什么完全无关，只是在「稀释错误」，信号利用率很低；整组全错时 GRPO 优势直接为零。负样本需要的是一个显式的纠错目标，即向 success sibling 对齐，拿稠密的纠错监督。
  • 正样本走 GRPO。正样本若拿去蒸馏另一条不同的正确解，等于把模型往一个预设标准答案上拉，会压缩解空间并注入分布错配的梯度，训练容易不稳；GRPO 抬高的是这条轨迹自身已被验证正确的 token，既 on-policy 又保留多样性。

一句话：负样本要的是纠正目标，正样本要的是强化自身。

难度路由：用历史通过率回答「学会了多少」

第二阶段内，正样本虽然都走 GRPO，但不同难度题从 GRPO 的收益并不一样：过难题很少给出可泛化的正确轨迹，过易题组内奖励同质、只能强化表层模式，中等难度恰在能力边界、最受益于探索。DRIFT 的做法分三步：

  1. 计算每个问题的瞬时通过率（一组 rollout 中正确数占比，组大小通常只有 8 或 16 ，单次估计波动很大）；
  2. 与历史通过率做指数滑动平均（EMA）平滑，得到跨 batch 可追踪的掌握程度估计，而非单次采样噪声；
  3. 按通过率分困难/中等/简单三档，对 GRPO 信号加权：难题档权重直接取 0（字幕口径），简单题取 0.5（字幕作「KA 等于 0.5」），中等题取 1 做全力探索。

Q&A 中讲者补充，难度档位随训练动态迁移：题目只会随模型变强从难题档滑向简单档，配合多次 rollout 判定与 warm up 阶段，真难题在一开始被误判为简单题的情形基本不会发生。

节奏门控：把信用压到推理转折点上

标准 GRPO 把同一个序列级优势平摊到每个 token，逗号、换行符与决定答案对错的推理步骤拿到一样的信号。节奏门控在 token 级再做一层分配，且不需要额外奖励模型或过程标注：参照系就是已经构造好的特权自教师。设计原则是：只有当一条已被验证正确的学生轨迹，在「教师比学生更快消解不确定性」的位置上表现出创新时，才放大这个 token。两个因子分别刻画两个条件：

  • 被验证的创新因子 $B_t$ ：在每个 token 位置取学生与教师对实际采样 token 的对数概率之差，只保留学生高于教师的正部，再过 $\tanh$ 映射到 0 到 1 。背后的判断是：教师拿了特权信息、天然知道答案长什么样，未必处处优于学生；若学生在某位置比教师更自信且轨迹最终正确，说明它走的是属于自己的正确路径，这正是要保留的推理。选 $\tanh$ 而非 sigmoid 或 ReLU，是因为自变量只取正部时需要一个有界、单调、且小偏离敏感、大偏离不无限放大的映射。
  • 不确定性消解因子 $G_t$ ：用窗口内熵的变化率定义「熵下降速率」（drop），即当前位置前后窗口平均熵之差的正部；学生的不确定性消解等于教师 drop 减学生 drop 的正部，再过一层 $\tanh$ 。讲者强调比较熵的绝对值没有意义（教师看过成功轨迹，整体置信度存在系统性落差），但比较变化率有意义：教师熵下降显著快于学生、学生还在摇摆的位置，就是真正的推理转折点。论文中给了一个引理：熵轨迹局部近似线性时，drop 恰等于窗口长度乘以负的局部斜率，且对常数偏移不变。

最终 token 权重写为：

$$w_t = 1 + \beta \cdot B_t \cdot G_t$$

其中 $\beta$ 是 0/1 开关，只当样本落在中等难度区间时才为一，从而把 token 级机制与问题级路由锁在一起。两个因子都在 0 到 1 之间，所以权重被严格限制在 1 到 2 ：在正优势轨迹上，节奏门控只会增益、不会改变梯度更新方向。讲者也坦承，单用创新因子时权重会以一定比例落在格式符、连接词、标点等无价值 token 上，第二个因子正是为约束这一点而加。

自蒸馏分支本身用 JSD 而非前向/反向 KL 对齐师生分布：前向 KL 偏 mode covering、收敛慢，反向 KL 偏 mode seeking、易过早收敛到确定性输出；在师生同步演化的场景下，对称且有界的 JSD 训练更稳定（字幕口径）。

成功缓冲：正样本稀缺时的兜底

没有正样本就没有 success sibling，没有 success sibling 就没有特权教师，SDPO 分支会直接失去梯度信号——这个问题对 DRIFT 比对一般 RL 框架更核心。成功缓冲的做法很工程化：为每个训练样本维护一个 buffer，记录其历史正确轨迹；前若干个 epoch 只累积不使用，之后当同一难题再次出现且当前一组 rollout 一条正确样本都采不出来时，从 buffer 回放一条历史正确轨迹作为 success sibling 交给教师。容量设为 3（字幕口径），满了用新轨迹替换最早进入的那条（FIFO），回放时均匀采样。小容量加 FIFO 意味着池中始终是最近若干次的成功、而非训练初期质量参差甚至蒙对的轨迹，池内轨迹质量随策略变强滚动上升，特权信息也越来越好，与固定教师的经典 OPD 形成对照。

对「历史轨迹会不会引入分布偏移」的质疑，讲者的解释是：被取回的轨迹从不作为梯度信号进入更新，只作为特权上下文喂给已经 stop-gradient 的教师，教师读完后在当前学生的 on-policy 分布上重新产生条件分布，被蒸馏的是这个分布。相当于教师做了一次隐性信息加工，只吸收自己能理解、能适配当前语境的那部分历史信息，是一个隐式软过滤器。Q&A 中还补充，buffer 实际内存占用只有几百 MB 量级（字幕口径），本质是兜底逻辑。

实验与消融

实验设置与 SDPO 原工作对齐：多学科数据集（字幕作「SCINALL」，应为 SciKnowEval）加工具调用数据集（字幕作「to use」，应为 ToolAlpaca），共五个基准；主模型 Qwen3-8B，另在 Qwen3-4B 与 OLMo 3-7B（字幕作「欧盟 37B」）上验证泛化；全部实验在 8 张 H200 上训练 400 步以上，按训练步数而非时间报告以便跨环境复现（以上均为字幕口径）。

主结果：Qwen3-8B 上 DRIFT 平均 79.5% ，比最强基线 SRPO 高 2.1 分、比起点高约 30 分，且每个任务都排进前二，不是靠牺牲某个领域换来的。工具调用任务上优势最突出，达到 79.2% ，分别比 GRPO 高 13.5 分、比 SDPO 高 10.7 分；讲者的解释是工具调用的正确性由格式与 schema 定义（action 名、参数结构、字段约束），这类知识可迁移，一条成功示范能直接惠及其他样本，而学科知识更绑定具体题目、复用性弱，增益更温和。跨模型结果：Qwen3-4B 上 74.6 、OLMo 3-7B 上 72.8 ，均为最高平均分；起点越弱增益越大，OLMo 3-7B 起点只有 30.5% ，DRIFT 拉高了 42.3 分，原因是弱起点时正样本极度稀缺、GRPO 优势坍塌最严重，成功缓冲的特权回放正好填上这个空洞。对 SRPO 的领先随规模扩大（4B 上 0.4 分、8B 上 2.1 分），讲者将其与「自我教学能力随规模涌现」的观察对应。

消融（节奏门控只定义在 GRPO 分支上、脱离难度路由没有独立定义域，故二者联合消融）：去掉难度路由平均分从 79.5 掉到 74.1 ，去掉成功缓冲掉到 74.9 ，去掉 warm up（两阶段课程）掉到 71.3 ，是三者中最严重的一项（以上均为字幕口径；论文 Table 3 中去热身一栏作 71.7 ，以论文为准）。另一个被讲者特别提到的曲线观察：训练到 400 步时 pass@k 与 avg@k 仍未重合、pass@k 还在缓慢上升，与常见 GRPO 训练后期 pass@k 下降、avg@k 上升直至趋同的形态不同（字幕口径）。

边界与讲者自陈

讲者明确列出边界：当前框架依赖可验证奖励（答案对错可被机器判定），适合科学问答、工具调用这类任务；到了没有明确验证器的开放式生成场景，评分标准与特权信息如何构造都需要重新设计，这是他们下一篇工作的方向。自进化也不是无上限的：训练到一定程度会到达瓶颈，熵崩塌等问题在工程中常见，需要不断调参处理。不用 SFT 做预热的原因也被问到：所用数据集上基座初始能力已够（如 Qwen3-8B 在最弱学科上的 pass@16 已有约 30 ，字幕口径），SFT 预热只在需要工具格式对齐或初始知识注入时才有必要。

5可迁移

  • 把「信号何时用、用在哪」做成显式机制，而不是在 GRPO 与蒸馏之间站队：问题级用可追踪的学习状态（历史通过率 EMA）做路由，token 级用师生分歧与熵变化率定位转折点，这套两级分配视角可以直接借到任何 RLVR 训练里，先从「负样本给显式纠错目标、正样本只强化自身」这条不对称原则开始试。
  • 正样本稀缺时的兜底设计值得抄：跨 batch 保留每题最近的少量成功轨迹，但只喂给 stop-gradient 的教师作特权上下文、不直接进梯度估计，用「教师重述」绕开离线回放的分布偏移问题，比重要性采样回放简单得多。
  • Infra 视角：DRIFT 的组件都是训练循环内的轻量状态（每题一个通过率 EMA、一个容量 3 的小 buffer），内存与计算开销都小；真正的成本敏感点在 warm up 与正式阶段的切换时机，以及 rollout 组大小对通过率估计噪声的影响，调参时应先盯这两处。

6疑问 / 下一步

  • 难度三档的阈值与权重取值（0 / 0.5 / 1）是经验设定还是有调参依据，讲授未展开；通过率 EMA 的衰减系数同样未给出，需查论文。
  • 节奏门控中熵窗口长度与两个 $\tanh$ 因子的敏感性、JSD 对齐的具体形式（字幕只给动机），以及 DRIFT 与 SRPO 的逐任务完整数字表，都需要回到论文核对。
