## 一句话总结

ProRL 的回答是：RL 能真正拓展推理边界，但前提是把训练做长、做稳、做杂——延长训练步数、多样化任务（数学/代码/STEM/逻辑/指令跟随）、用 KL 正则维持可持续熵并周期性重置 reference policy，让 1.5B 模型在 base 模型 pass@256 恒为零的任务上学到从零到一的能力。

## 核心

### 1. 背景/问题：RL 到底有没有教模型新东西？

这是 2025 年推理模型研究的核心争议。质疑方（字幕提到清华等机构的工作）用 pass@k 曲线论证：RL 只是提高了对已有潜在解的采样效率，K 大到 256–1024 时 base 模型反而不弱于 RL 模型，RL 没有改变能力分布、只有「温度调节」式的幻觉提升（字幕 [07:03]–[08:15]）。讲者的立场是：这个结论可能来自两个偏差——实验任务过度集中在预训练里反复出现的数学题，以及训练步数太短（只训几百步），「探索还没有开始就已经结束」（字幕 [32:33]–[32:55]）。AlphaGo Zero 只用 40 天、无人类数据就超越所有前代，说明 RL 在别的领域能产生真正的新能力；大模型 RL 没复现这一点，问题在训练范式不在 RL 本身（字幕 [08:47]–[09:12]）。

### 2. 方法：ProRL 的三件套

ProRL（prolonged RL，延长式强化学习）建立在 GRPO 之上，核心策略有三：

- **借 DAPO 的两个技巧**：动态采样（按难度筛选样本、提升多样性、避免局部最优）与分离 clip 上下限（clip-higher，字幕口径下限 0.2、上限 0.3 的设置训练最稳健）（字幕 [12:57]–[13:34]、[15:01]–[15:17]）。
- **可持续熵机制**：讲者强调熵的持续上升或持续下降都不利，如同梯度爆炸/消失。做法是引入 KL 正则把熵温和收束到一个低而平稳的水平——实测加 KL 后熵略低、但推理性能不降反升并在后期反超所有对照设置（字幕 [16:05]–[17:21]）。KL 权重字幕 Q&A 口径约 0.005，需按模型微调，判断标准就是盯熵的稳定性（字幕 [62:46]–[63:28]）。
- **周期性重置 reference policy 与优化器状态**：不重置时 KL 散度持续飙升、波动剧烈乃至崩溃；周期性重置后 KL 回落再爬升，形成锯齿形的「探索—归零」节奏。重置时机的经验判据：验证集性能不再提升时就 reset（字幕 [18:45]–[19:38]、[47:27]–[48:05]、[57:55]–[58:29]）。

配套设置（多来自 Q&A，均为字幕口径）：训练只用 8K 上下文（讲者认为对当前任务足够，AIME 级别题目人类专家平均解长约 3K）；只用 outcome reward、无 format reward；8K 内未正常终止给一个小 penalty；rollout 16、BF16；loss 聚合用 token-sum；不需要全程冷启动新数据，几万量级（几 10K）的开源数据配合难度动态采样可复用多 epoch，10K 数据训 2000 步可行。

任务侧是另一半的方法：不用只喂数学题，而是覆盖数学、代码、STEM、逻辑推理（Reasoning Gym，字幕作「rain jym」）与指令跟随五大类，让模型在更广的推理空间里探索（字幕 [11:07]–[11:51]）。

### 3. 实验：1.5B 打出的成绩单

基座是 DeepSeek-R1 蒸馏的 1.5B 模型（字幕作「deep sick r one disco 千万 1.5B」，已有 CoT 能力——讲者明确 ProRL recipe 希望起点模型带 CoT 能力，无 CoT 的纯 base 是另一问题，字幕 [42:42]–[44:09]）。

- 对位同规模最强开源基线，六个推理方向（数学、代码、逻辑、STEM、指令跟随等）全面占优；数学各主流 benchmark 平均高出约 10–30 分，AIME 提升 19.6（字幕 [21:10]–[21:28]）；代码平均提升约一倍，部分任务从 21 分涨到 42 分（字幕 [21:28]–[21:37]）。
- 泛化项最亮眼：GPQA 从 15.9 提升到 41.8（字幕 [22:03]–[22:10]）；Reasoning Gym 上原模型准确率只有约 1%，训练后大幅跃升（字幕 [21:37]–[22:00]）。
- 越过专精模型：对数学专精与代码专精的同尺寸模型（DeepCoder-1.5B 等）多数任务领先，代码部分任务提升超 50%，仅 HumanEval+ 低 1.4 分、整体平均仍 +6.5 分（字幕 [22:50]–[23:26]）。
- 逼近 7B：与 DeepSeek-R1 蒸馏 7B 对比多数任务接近，数学平均 60.14 对 7B 的 63，STEM、指令跟随、Reasoning Gym 上反超（字幕 [23:53]–[24:31]）。

### 4. 延长训练还涨吗？2000 步 → 3000 步

论文发布时模型训了约 2000–2500 步；讲者展示了继续训到 3000 步的对照（字幕 [25:17]–[26:29]）：整体平均 60.02 → 61.7，代码 pass@1 32.3 → 36.4，Reasoning Gym 59.1 → 62.5，指令跟随 66 → 70.8，GPQA 41.8 → 41.3 基本持平。结论：3000 步仍未见顶，长训练的收益没有饱和迹象；但讲者也坦承 3K 之后到 8K、10K 步会怎样「暂时没有证据」，实验还在继续（字幕 [44:36]–[46:28]）。

### 5. 关键证据：RL 真的拓展了边界吗？

讲者给出三层证据回应质疑方（字幕 [26:42]–[31:37]）：

- **pass@k 对照**：在部分 out-of-domain 任务上，base 模型无论 K 从 1 加到 256 准确率都几乎为零，而 ProRL 模型随 K 增长逼近 100%——这不是采样效率问题，是原空间里根本不存在的解被学出来了。Q&A 里讲者把这称为「最直接的证据」（字幕 [38:58]–[40:07]）。
- **从零掌握与分布外泛化**：某任务上 pass@1 从 0.077 一路涨到 100%；图规模从训练分布内（<10）放大到 20，终模型仍保持 70% 以上 pass@k。
- **新颖性与弱项定律**：用 creativity index（推理路径与预训练语料的重合度）衡量，长训后推理路径新颖性更高；18 个代表性子任务、pass@128 的分析显示负相关——base 越弱的任务 ProRL 提升越大，RL 不是在熟悉任务上重复优化，而是在模型最弱、预训练重合度最低处挖出新能力。讲者对此的一个解释是跨任务泛化：在别的推理任务上学到的能力迁移到了 base 恒零的任务上，这正是他们最想看到的图景（字幕 [65:14]–[66:35]）。

### 6. 结论/观点（讲者五点总结，字幕 [31:47]–[33:47]）

1. ProRL 显著拓展了基础模型的推理能力边界，解法更多样、更有创造性；
2. 用计算越多、探索出的解法越多样，与「RL 只是温度蒸馏/采样效率」的传统观点截然不同；
3. 既往「RL 无效」的结论很可能源于任务单一（过度集中于预训练已过训的数学）与步数太短两个偏差；
4. ProRL 的关键配方是任务多样化 + 稳定的熵控制 + 周期性重置参考策略；
5. 开源的 1.5B 模型已在部分任务上接近甚至超越 7B，并在分布外任务上展现泛化。

其他值得记的讲者判断：response length 与能力无必然正相关（更长只是 test-time scaling 的一个手段，32K 压缩到 8K 也能保效果，字幕 [34:38]–[36:30]）；multi-turn RL + 工具使用是他正在投入的方向；ProRL 的能力上限「现在不知道」，期望是靠不断引入更难任务而无上限（字幕 [44:36]–[45:34]）；数据量不是关键、步数才是，难度采样的偏好是「难但非 beyond」的问题（字幕 [40:35]–[41:30]）。

## 可迁移

- RL 训不动时先查两个变量再下结论：是不是任务太单一（全挤在预训练过训的分布上）、是不是步数太短。给长训留预算，并把「验证集停滞 → 重置 reference policy」做成训练循环里的标准动作。
- Infra 视角：ProRL 的配方（GRPO + DAPO 技巧 + KL 熵控 + 周期重置）可直接在 verl 上拼装；8K 上下文 + token-sum loss + outcome-only reward 的极简设置在 1.5B 量级已被验证，长上下文不是推理 RL 的入场券——算力优先花在步数和任务多样性上。
