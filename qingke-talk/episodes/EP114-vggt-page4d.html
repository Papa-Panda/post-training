2一句话总结

讲者先剖析 VGGT 为什么在动态场景失效：它学的是帧间 patch 对应所编码的极线几何，而物体的 3D 运动会破坏极线约束，使前景被融进背景；PAGE-4D 的解法是按两个方程在动态下成立范围的不同，把任务拆开——几何估计要用静动态全部信息并显式估运动，位姿估计只许用静态子集——并用一个学到的 mask 限制 camera token 只注意静态部分，从而在同一框架里统一处理动态场景的深度与位姿估计。

3核心

动机：动态让视频的几何关系失效

文本、图像都有成熟表示，视频表示的难点在动态信息：相机在动、前景物体也在动。静态场景里像素位移纯由相机运动决定，可用极线几何描述；一旦物体自身在 3D 空间中从一点移动到另一点，像素位移同时包含相机运动与物体 3D 运动，静态几何关系被破坏（字幕 [01:49]-[02:51] 口径）。PAGE-4D 要解决的就是含人、车、机器人等高度动态元素的视频表示与 3D 感知。

对 VGGT 的剖析：它到底学了什么

VGGT 的结构（字幕口径）：每帧图像经编码器切成 patch token 并附加一个 camera token，拼接后交替做 global attention（帧间）与 frame attention（帧内），再由各预测头输出深度、相机位姿等。

讲者的分析结论是：VGGT 并没有在直接学像素位移，它学的是帧间 patch 的对应关系，这种对应同时编码了相机位姿信息与几何信息，极线几何是其底层约束。两个证据：

  1. 动态物体在中间特征里是异常点：可视化各层的特征统计（主成分/方差/能量类指标，字幕不可辨）可见，动态物体的特征与静态背景显著不同——即动态物体被模型当成违反极线关系的区域处理。
  2. camera head 重、depth head 轻：表示主要沉淀在 token 里，深度头很轻即可解码；而相机位姿需要很重的相机头从 camera token 中解码（字幕 [10:26]-[11:04] 口径）。

失效表现（定性例子，字幕口径）：滑板运动员场景中前景与背景被融合、难以区分；人物拍墙的视频里，人被融进墙面与地面。共同点是前景被当作背景的一部分感知。

PAGE-4D：把两个方程的成立范围拆开

讲者从方程出发推导设计。静态场景下，对所有未遮挡的像素对应，下面两类关系同时成立：由深度与位姿决定的重投影几何关系，以及极线约束 ， $\hat{x}_t^\top E \hat{x}_r = 0$ ，（字幕 [12:01]-[12:37] 口径，符号按标准极线约束还原）。

动态场景下两者分化：

  • 几何（深度）估计的方程多出一项 3D 运动：要估准深度，必须把运动也估出来，因此几何估计应当同时使用静态与动态部分；
  • 位姿估计的极线方程只在静态子集上成立：动态像素会给位姿带来系统性偏差，位姿估计应当只用静态部分。

这构成一个多任务冲突：两个头需要不同的输入子集。PAGE-4D 的解法是学一个动态/静态 mask 并作用在注意力上：camera token 只注意静态部分，patch token 对静动态一视同仁（字幕 [17:53]-[19:10] 口径）。实现上直接物化这个 mask 尺寸过大（随帧数与 patch 数增长），讲者提到借鉴 FlashAttention 式的分块/核内处理避免显式构造大 mask，并给出由 camera token 与 patch token 构造 mask 的具体做法（该段字幕严重损坏，细节以论文为准）。

结构上（字幕 [23:11]-[23:57] 口径，层数待核）：前段层先预测 mask，中间层用带 mask 的动态全局注意力建模，最终几层做预测输出；定性结果显示雪景、人物等场景中 VGGT 把前景与远处背景融合，而 PAGE-4D 能把前景与背景分开。视频深度估计与位姿估计的定量结果字幕中没有可辨数字，此处不录。

后半段：3D 沙盒与物理理解（Q&A 延伸）

讲授后段与 Q&A 涉及的另一条线：VLM 回答不了物理类问题（如桌子与厨房的距离、物体移动的速度与位移），因为它没有 3D 理解。讲者团队的做法是先为每个物体构建 3D 边界框、剥离外观只留几何，构成「沙盒」式的认知地图再喂给 VLM，对位置、距离、运动类问题能给出较准的回答；结合视频扩散模型生成多视角、再用前馈方法建 3D，可让同一组边界框在各视角中一致出现（字幕 [38:34]-[41:51] 口径，工作名不可辨）。

Q&A 中可辨认的观点（均为字幕口径，不确定性高）：

  • 世界模型的定义在不同领域差异很大（动作条件预测、语言 token 条件预测、重建式等），讲者倾向认为重建模型最终会被生成模型框架覆盖，但这只是假设；
  • 基于对应关系的模型在相机静止、仅前景运动的视频上表现差（它假设相机在动），而单目深度加对齐的方法在此类场景更好——两条路线正在走向「神经前馈初估 + 全局对齐优化」的结合；
  • mask 不能直接套用，需要精细调整，否则性能很差；
  • 显式表示（如 3D Gaussian）与隐式表示之争未定，讲者总体更看好隐式表示，但显式表示在预计算场景的渲染速度上仍有优势；
  • 团队也在尝试事件相机与 RGB 结合来理解动态过程（初步结果，字幕口径）。

5可迁移

  • 分析一个多任务 3D/感知模型时，先问每个预测头依赖的几何方程在目标场景下还成不成立：本期失效不是模型容量问题，而是极线约束被 3D 运动系统性破坏，先定位约束失效再谈改结构。
  • 「按子集分工」的注意力 mask 模式可迁移：当某个子任务只应在数据子集上成立（如位姿只用静态点），与其在 loss 里降权，不如直接限制对应 token 的注意力可见范围。
  • 诊断手法可复用：可视化中间层特征统计找异常区域、用「预测头轻重」判断表示沉淀在哪，是低成本剖析黑盒视觉模型的两招。
