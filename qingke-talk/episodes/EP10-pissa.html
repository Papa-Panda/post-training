2一句话总结

PiSSA 与 LoRA 架构完全相同，只改初始化：对预训练权重做 SVD，把 top- $r$ 主奇异值构成的成分放进可训练的 adapter 、把其余残差冻结为新的基座，等于让微调一开始就沿着模型「主要功能的方向」更新，绕开 LoRA 高斯加零初始化带来的「梯度一个为零、一个是随机方向」的冷启动病；其量化版 QPiSSA 因为只需量化已经去掉主成分的残差，初始量化误差比 QLoRA 小约五分之一（字幕口径）。

3核心

引入：参数高效微调要解决的是显存账

全参数微调直接但贵：讲者引论文口径指出，微调 65B 模型需要约 780GB 显存、170B 模型约 1.2TB（字幕口径），对多数实验室不现实。LoRA 的假设是微调前后的权重变化 $\Delta W$ 低秩，于是冻结基座、只训练两个小矩阵 $A$ 与 $B$ 的乘积，训完还能合并回基座、推理零额外分支。但讲者的切入点是：LoRA 的毛病不在结构，在初始化。

LoRA 的初始化病：梯度「又小又慢又乱」

LoRA 的 $A$ 用高斯初始化、 $B$ 用零初始化，保证插入瞬间不改变模型输出；讲者当场对两个矩阵求导指出后果：初始时刻一个矩阵的梯度恒为零，另一个的梯度由随机方向决定——「一个是零、一个是随机方向」，合起来就是「又小又慢又乱」。实证上就是 loss 曲线前 100 步几乎不降、梯度范数全程偏小（字幕口径，见 LLaMA-2-7B 实验段）。讲者的定性判断是：LoRA 冻结了原模型的能力，却在拿噪声和零去拟合增量，所以收敛慢、终点也差。

PiSSA 方法：训主成分，冻残差

对每个待微调权重矩阵 $W$ 做奇异值分解：

$$W = U \Sigma V^\top$$

取 top- $r$ 主奇异值与其奇异向量初始化 adapter ：

$$A = U_{[:r]} \Sigma_{[:r]}^{1/2}, \qquad B = \Sigma_{[:r]}^{1/2} V_{[:r]}^\top$$

剩余部分构成冻结的残差矩阵：

$$W^{res} = U_{[r:]} \Sigma_{[r:]} V_{[r:]}^\top$$

初始化时 $W^{res} + AB = W$ ，模型输出与原模型逐点一致，训练中只更新 $A$ 与 $B$ ——即只微调原权重的主成分。由于 $A$ 与 $B$ 不再是噪声与零，初始梯度既大且方向对齐模型的主要功能，梯度范数的形状与全参数微调高度相似（字幕口径）。工程上唯一新增步骤是一次快速 SVD，几秒量级（字幕口径：rank 16 约 6 秒），架构与训练代码与 LoRA 完全复用。

QPiSSA：量化误差为什么天然更小

QLoRA 把基座做 4-bit NF4 量化、adapter 保持高精度；讲者指出它的一个结构性事实：初始化时 adapter 为零，所以 QLoRA 的初始量化误差就等于「直接把原模型 4-bit 量化」的误差，一点没省。QPiSSA 改变量化对象——只量化残差 $W^{res}$ ：主奇异值已经被抽走，残差的奇异值量级小得多（讲者给的印象量级：原始矩阵奇异值从约 20 往下，误差矩阵从约 0.5 往下，字幕口径），且残差分布更接近高斯分布，更贴合 NF4 按正态分位数划格子的假设，于是格子利用率更高、误差更小。在 LLaMA-2-7B、LLaMA-3-8B、LLaMA-3-70B 三个模型上，QPiSSA 相对直接 4-bit 量化减少约 20% 量化误差，且在每一类层（注意力 QKVO、MLP gate/up/down）上都优于专门做误差修正的 LoftQ（字幕口径）。推论是：4-bit 的 QPiSSA 训出的模型效果可以超过不量化的 LoRA，A100 才训得动的模型用 3090 就能训（字幕口径）。

实验：收敛速度与终点双测

讲者用三层证据：玩具实验（两层 MLP、手写数字奇偶划分预训练/微调）直观展示 PiSSA 收敛略快于全参数微调、LoRA 全程落后；主实验在 LLaMA-2-7B 上以 rank 128、MetaMathQA-395K 数据、batch size 128、3 个 epoch 对比（字幕口径），PiSSA 的 loss 全程贴近甚至低于全参数微调，GSM8K 上从 1000 步到 9000 步持续领先 LoRA、部分点超过全参数微调，讲者引为「直接超了 LoRA 约 11%」（字幕口径）。任务面覆盖 5 个生成任务（数学、代码、对话类）与 8 个语言理解任务，模型面从 7B 到 LLaMA-3-70B、含 MoE 结构，结论一致（字幕口径）。消融确认三点：训练主奇异值优于训练中间或最小奇异值（loss 与准确率双测）；rank 越大初始量化误差越小、rank 128 时效果接近全参数微调；PiSSA 偶胜全参数微调，讲者的解释是全参数微调在简单微调任务上过参数化、更难调。

工程使用：零代码切换与四种保存法

PiSSA 已合入 HuggingFace PEFT（字幕口径），在 LoRA 配置里把初始化方式设为 PiSSA 即可，其余代码不动；讲者团队也在 HuggingFace 上放了预初始化好的模型（字幕口径：上月下载量约 2700 次），含 LLaMA-3-70B、Qwen2-72B 的量化版，约 30GB 可下载。实践参数： $\alpha$ 与 $r$ 保持一致（缩放系数为 1）、dropout 建议设 0（主成分被丢弃会伤效果）；不要直接丢弃 $W^{res}$ ，它量级虽小但删掉损失很大。保存有四条路：合并成单分支模型（推理快、存储大）、存 adapter 本体（每次加载重做 SVD）、利用 $\Delta W$ 可写成 rank 翻倍的普通 LoRA 无损转存（可与多个 adapter 共挂同一基座），以及讲者最推荐的分开保存，即只存 $W^{res}$ 与 adapter 两部分（存储小、加载不重算 SVD）（字幕口径）。

Q&A 要点

  • 对 SVD 数值稳定性/奇异值分布的依赖：权重越低秩，收敛快与量化误差小的收益越明显；低秩性不显著时也仍有收益，因为训的始终是最重要的那部分（字幕口径）。
  • 数据分布长期漂移：训好的 PiSSA 可以合并回模型、转成 LoRA 形式、或多个 adapter 共挂；后续继续训可以继承主奇异值部分、逐步加大 rank，不需要定期从头重训（字幕口径）。
  • 过拟合/欠拟合：与一切 PEFT 相同，由 rank 与数据量匹配决定；任务难就加大 rank，数学任务上 rank 到 128 才追平全参数微调，有的任务 rank 4-8 就够（字幕口径）。
  • 实验模型都是 base 版而非 chat 版，为了看各类基础能力；chat 版在其 HuggingFace 仓库中另行提供（字幕口径）。

5可迁移

  • 对 PEFT 选型的直接清单：初始化不是免费细节——LoRA 的高斯加零初始化决定了它前若干步在「挣扎」，凡是已有 LoRA 流水线，把初始化换成 PiSSA 是几秒成本、代码不变的替换，值得作为默认项做一次 A/B。
  • 对量化微调的启发：量化误差的大头来自权重的主成分；先把主成分抽到高精度 adapter 、只量化残差，是比事后误差补偿（LoftQ 式）更前置的解法，这一「先分解、再量化低价值部分」的次序可迁移到其他压缩场景。
  • Infra 视角：PiSSA 训完可无损转成 rank $2r$ 的普通 LoRA，意味着训练侧的方法创新不必要求推理/serving 侧改任何接口——新方法若能保持与既有 adapter 格式兼容，落地摩擦会小一个量级。

6疑问 / 下一步

  • GSM8K「超 LoRA 约 11%」是相对百分比还是准确率点数，字幕未说清；需要回论文表格对齐口径（论文口径可另查 Mistral-7B 上的对应数字，不与字幕混用）。
  • PiSSA 冻结残差的前提是「微调增量主要落在主成分方向」；在增量本身需要改动残差方向的任务（如学习全新格式/语言）上，这个假设何时失效，讲授未展开。
  • 讲者提到可以在 $W^{res}$ 上加 dropout 做进一步压缩，只是设想、未给实验；是否值得试取决于残差信息的实际冗余度。
