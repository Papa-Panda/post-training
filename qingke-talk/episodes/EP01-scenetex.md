## 一句话总结

把纹理生成从「逐物体」升到「整场景」：输入场景几何 + 文本提示，直接生成全局一致的场景级纹理。方法是多分辨率纹理场（2D UV 空间的 hash-grid 多尺度特征）+ instance-aware 的 cross-attention 纹理解码器，再以 VSD（variational score distillation）全局优化，用 CLIP / Inception Score 与用户研究双轨评测，定性与定量都明显优于 inpainting 系（Text2Tex 等）与隐空间优化系（Latent-Paint）。

## 核心

### 1. 背景/问题：逐物体的传统管线贵、乱、难改

传统管线是先把场景拆到每个物体，逐个设计纹理再贴回场景背景。讲者列了三个痛点：

1. **昂贵耗时**：每件家具都要重复设计一遍，雇三维设计师成本很高；
2. **外观不一致**：逐物体独立生成，物体之间风格不协调（欧式家具放进中式客厅）；
3. **难修改**：客户一句「看着不协调但说不出哪不协调」，就要推倒逐物体重做。

学界现有纹理生成只做物体级，两条路线各有硬伤：

- **Inpainting 系**（Text2Tex、TEXTure、Text2Tex Fusion）：拿现成 2D diffusion 从多视角往 3D 面上投，不需训练，但有局部/全局不一致（左右两侧纹理对不上）和伪影；搬到场景上还会出现接缝线（seam）、风格不一致、loop closure（绕一圈回不到起点外观）三类问题，因为场景难以布密集相机阵列。
- **隐空间优化系**（Latent-Paint）：在 latent 里用 SDS 类损失优化、再解码回 RGB，全局一致，但高频信息在 encode/decode 中丢失，出现「补丁状」色块伪影；场景上还会凭空生出几何不存在的物体（灯、沙发犄角）、收敛慢。

讲者据此定下四个目标：任意位置高清真实、全局视角与几何一致、无接缝与拉伸、大小物体保真度均匀。对应的两个技术手段：**全局优化**（解决 seam 与 stretch）+ **灵活的多尺度表征**（解决尺度不一致）。

### 2. 方法/设计：多分辨率纹理场 + cross-attention 解码 + VSD 全局优化

- **多分辨率纹理场（Multi-Resolution Texture Field）**：借 Instant-NGP 的 hash grid 思路但搬到 2D UV 空间。对任一 UV 坐标，在每个尺度（讲者举例 4×4、8×8、16×16 的网格分辨率）上取邻近四格特征做双线性插值，多尺度拼接成 UV embedding——粗尺度管颜色与整体纹理，细尺度管高频细节。
- **Instance-aware cross-attention 解码器**：解决「同一物体左右两边互不可见」的一致性问题。利用已知的 instance mask，在 UV island 上预先采样一批固定锚点作为全局信息；解码当前点时把它作 query、锚点作 key/value 做 cross-attention，加 skip connection，再经一层小 MLP 映射到 RGB。这样当前点「看不见其他区域也知道它们长什么样」，物体内风格一致。不同物体之间的一致性讲者坦承是「比较隐式的处理」：尽量用广角镜头在一个 view 里框进更多物体，多 view 覆盖后自然一致。
- **优化目标**：渲染出的 RGB 经预训练 SD 的 VAE encoder 编 latent，与文本提示、depth map 一起进 VSD 模块（SDS 变种）算 loss，梯度回传更新纹理场。多相机视角循环优化直至全局收敛。几何条件目前只用了 depth（讲者承认这是较弱的约束）。

### 3. 实验/实战

- **评测设置（字幕口径）**：10 个 3D-FRONT 场景 × 每场景 2 种纹理 = 20 个场景，每场景随机渲染 200 个视角，共 4000 张图跑 CLIP Score（与文本提示的相似度）和 Inception Score（真实感），两者都是越高越好；讲者自评这类自动指标「就像体脂秤，只能给大概参考」。
- **用户研究**：每场景随机取 10 个 view 给专家用户打分，两个维度各 1–5 分：真实感/一致性，以及与文本提示的契合度；结果均优于所有文本驱动基线（含 MVDiffusion）。
- **定性对比**：Latent-Paint 在场景上「一眼假」且糊；MVDiffusion 有接缝与视角死角；Text2Tex 分辨率尚可但接缝、伪影明显，物体表面不平滑；SceneTex 更真实自然。
- **三项消融**：① 直接优化 RGB 纹理图（不用纹理场）会产生波纹状假纹理；② 去掉多分辨率后大物体（沙发、墙面、地面）会出现「想生成复杂纹理又生成不出来」的波纹；③ 去掉 cross-attention 解码器，同一块地毯在不同 view 下红白不一致。
- **应用展示**：同场景风格化（巴洛克 / 波西米亚 / 法式田园 / 日式）；与 MeshGPT 类几何生成方法串联做「从无到有」；在 ScanNet 真实重建场景上重纹理化，精度远高于相机原图；室外铁匠铺建筑生成雪天外观。
- **算力口径（Q&A）**：分辨率拉满（渲染 768×768）时 VSD 需要多次前传 + LoRA + ControlNet，约 15 小时 / 场景（A6000）；降质量后 2080 也能跑（约 10G 显存可用）。

### 4. 结论/观点（事实 vs 观点分开标注）

讲者自陈的两个局限（事实层面的自评）：

1. **光影 baked-in**：生成结果里带固定的光照效果，不能像白模纹理那样下游再加任意光效与材质——讲者希望下一步改用基于物理渲染的方法，这是他认为数字资产能被游戏/电影下游直接利用的前提。
2. **几何幻觉**：VSD 先验会把几何上不存在的东西「合理地」加出来（空柜子上方生出一盏灯，因为 SD 认为该风格的场景就该有灯）——这属于先验幻觉，讲者给的缓解方向是把 depth 换/叠加成约束更强的 normal、canny edge 等条件。

观点层面：讲者认为这类「场景级整体生成」才是纹理生成的正确粒度，逐物体路线在风格一致性上没有出路；但对细粒度语义控制（「绿色的桌子、红色的椅子」）他承认目前做得不好，因为生成时没有对纹理图的语义做约束。

## 可迁移

- **多尺度表征应对尺度悬殊的对象集合**：粗尺度编码整体结构、细尺度编码高频，这套「分层特征 + 双线性插值拼接」与 coding 数据里按仓库/文件/函数分层做上下文索引是同构的思路——先粗粒度定位、再细粒度取细节。
- **用固定锚点 + cross-attention 把全局信息塞进局部决策**：与 RL infra 里用小型全局状态汇总（如归一化统计量、全局 critic）约束局部更新的做法可类比：当前更新点看不见全局，但可以通过一组固定「参考点」获得全局一致性信号。
- **评测纪律值得抄**：自动指标（CLIP/IS）只作一阶筛查，最终结论靠人评的真实感与任务契合双轨——对应到后训练评测，就是自动 benchmark 与人工偏好评测不能互相替代。

## 疑问 / 下一步

- 细粒度语义控制（指定某张椅子红色）在纹理场里如何加约束？讲者说目前没做——可能的路径是把 instance 级语义条件注入 cross-attention 的 key/value，值得对照论文实现细看。
- VSD 的幻觉问题本质是先验压过几何约束，和 LLM 里「先验压过上下文证据」的幻觉同源：depth 这种弱条件不够，normal/canny 更强——这条「约束强度阶梯」值得在别的生成任务里复用。
