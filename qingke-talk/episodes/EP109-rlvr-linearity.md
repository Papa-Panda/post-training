## 一句话总结

王天乐团队发现 RLVR 训练中存在贯穿权重、激活与输出 logits 的强线性：绝大多数权重随步数近似沿直线演化， $R^2$ 普遍大于 0.7 ，其机制是每步梯度只含约 0.03 相关度的有效信号、其余为噪声，累积后噪声相消而成直线；据此提出 logit 外推、权重外推与迭代式 RL-Extra 三种加速方案，在固定真实梯度步数预算下显著超过标准 GRPO，并解释了为何单纯调大学习率不能替代外推。

## 核心

### 动机：RLVR 的效率瓶颈与「冗余步骤」假设

讲者先摆 RLVR 的账：DeepSeek 训 R1-Zero 需约 8000 个 step；随训练深入推理链变长，单步耗时从几分钟涨到几十分钟；即便是 1.5B 的 DeepScaleR 模型，复现训练也要约 3800 个 A100 GPU 小时（约合 32 卡连续跑 5 天，字幕口径）。由此提出全场核心假设：RLVR 的训练步里有大量冗余，很多更新没有带来有效信息，只是在重复固有模式——标题里的「Not all steps are informative」即指此。

背景部分快速过了一遍实验要用的三个算法：GRPO（组内归一化优势、去掉价值网络）、REINFORCE++（用全局 batch 归一化替代组内归一化，修正按 prompt 归一化的偏差）、GSPO（把重要性采样与裁剪从 token 级提到 sequence 级，主要解决 MoE 训练的震荡）。讲者也交代了本工作的立场：对于「RLVR 是教新能力还是激发 base 模型潜能」的争论，他们的发现偏向后者——RLVR 主要是在调整训练初期就能观察到的高频模式的概率分布，并没有突破 base 模型的知识边界。相关的微观训练动态研究被拿来作铺垫：权重更新的稀疏性（约 20% 参数有有意义变化）、子空间学习（沿主成分的次要方向更新）、以及 LoRA 一类参数高效方法只训少量参数即可媲美全参——都说明 RLVR 的实际自由度远小于参数量。

### 核心发现一：权重、激活、logits 三层都是线性的

在复现 DeepScaleR 训练并逐参数拟合后，讲者给出第一组证据：单个权重的轨迹基本是直线，线性拟合的决定系数 $R^2$ 最高达 0.92，超过 80% 的权重 $R^2$ 大于 0.7，分布集中在 0.9 附近。逐层看，attention 与 MLP 矩阵在所有层 $R^2$ 普遍在 0.8 以上，与深度无关；唯一的例外是 LayerNorm 层，线性度显著偏低——讲者据此判断模型的核心统计特征在 RL 训练中保持稳定，线性变化主要发生在负责特征变换的矩阵上。

第二层证据在输出侧：以 AIME24 的 30 个 query 生成 token 为探针，token 的对数概率随步数同样线性， $R^2$ 集中在 0.9 附近。讲者把探针 token 分成三类，这个分类是全场最有解释力的部分：

- **高变化、高 R²**：以 wait、but、therefore 这类行为指示词为代表， $R^2$ 高达 0.975 ，对数概率线性上升，反映 RLVR 在塑造反思、修正这类推理行为；
- **高变化、低 R²**：随机波动的文本片段， $R^2$ 只有 0.027 ，无规律可言，是噪声而非信号；
- **基本不变**：数学计算类 token（如某步具体算式），对数概率几乎不动， $R^2$ 趋近于零——讲者的结论是 RLVR 不改变模型固有的核心计算能力，只优化推理行为模式。

第三层是中间激活：除第一层（直接承接 embedding、训练初期适应性波动大）外，各层神经元激活值的平均 $R^2$ 从第二层起快速攀升并稳定在 0.7 以上。跨场景验证覆盖多个基座（DeepSeek、Qwen 的 1.5B/7B、LLaMA 系 8B 等）与 GRPO、REINFORCE++、GSPO 三种算法，权重层与 token 层的 $R^2$ 都稳定超过 0.7——线性不是某个模型或算法的特例。

### 机制：每步梯度几乎全是噪声，直线是累积出来的

讲者对「为什么线性」的解释分两段。第一段针对权重：逐个检查每步梯度后发现，梯度本身既不线性也不恒定，它与权重最终收敛主方向的相关度只有 0.03；同时梯度的均值与标准差在全程基本恒定。于是每步梯度可看作两部分：一小份与主方向相关的有效信号（相关度 0.03）加上占绝大部分的噪声。单步看满是噪声，但大量步累积后噪声相互抵消，权重空间里就留下一条清晰的直线。

第二段解释输出为什么也线性。讲者把某层输出的变化展开：权重变化量与输入变化量的贡献里，一阶项占绝对主导，权重变化本身与二阶交叉项可以忽略，于是输出变化近似只由输入漂移经初始权重放大得到。用讲者的展开式说，输出变化量近似满足下式：

$$\Delta Y \approx W_0 \Delta X$$

直观含义是：权重沿直线走、激活沿直线漂，输出的对数概率自然也沿直线变——三层线性是同一个机制的三个投影。

### 三种加速方案：从 logits 外推到 RL-Extra

既然轨迹近似直线，就可以少跑步数、直接外推。方案一是 **logit 外推**：取前后两个 checkpoint 的 logits 向量，用一个由目标步数决定的系数做线性外推，直接预测未来步的模型输出，全程没有梯度计算开销。在 AIME24、AIME25 与一个域外 code 基准上，外推结果在准确率上全面超过标准 RL 训练（字幕口径）；讲者的解释是标准 RL 后期常有熵坍塌与过拟合，外推等于直接跳到理想化的后期状态，反而更稳。

方案二是 **权重外推**：同样的直线运算搬到参数空间，好处是产出的是可直接部署的完整模型。实验里固定两个 checkpoint、拉长外推步长，性能呈倒 U 形——先升、达峰、再降，说明单次外推有最优区间，外推过度会丢掉训练后期必要的方向修正。

方案三是为突破单次外推上限设计的 **RL-Extra**（字幕音作「RL Extra」）：一个周期内先跑少量真实梯度步（如 20 步）用真实奖励校准方向，再沿校准后的直线外推一大步（如 100 步），如此交替。固定真实梯度步数预算（200、400、800、1200 四档）对比标准 GRPO，RL-Extra 在域内 AIME24、AIME25、MATH500 上显著更好，域外 LiveCodeBench 不掉性能。按达到目标精度所需的真实步数计：达到 AIME24 准确率 0.40，某组参数下 RL-Extra 需约 900 步、标准 RL 约 1400 步（约 1.6 倍加速）；更激进的一组设置下达到 0.38 只需约 180 步对 1100 步（约 6.1 倍加速）。以上均为字幕口径，参数组细节以论文为准。

### 为什么不能直接调大学习率

这是讲授中论证最完整的一段对照。外推看起来像放大步长，但与调大学习率有本质区别：每步梯度与主方向的相关度只有 0.03，信号本来就弱、噪声占绝大部分，增大学习率等于把噪声的音量一起放大，只会让训练更不稳定。讲者给了实证：学习率调大后 AIME24 准确率从 0.42 掉到约 0.32、训练初期崩溃明显增多，再往上调则一开始就训不动。而 RL-Extra 是先校准、再外推：先用一小段真实训练确认当前直线方向，再沿这条已验证的轨迹大步走，避开梯度噪声最大的阶段。

讲者还用两个实验回应「线性会不会只是更新太小造成的假象」：其一，放大学习率后权重轨迹的 $R^2$ 仍在 0.7 以上，与训练是否稳定无关；其二，权重平均更新幅度实际超过 5%，在参数空间里是显著移动而非微扰。结论：线性是 RLVR 的固有属性，不是小步更新的副产品。

与相关工作的区分也被点明：Model Soup 的线性是不同模型在同一误差盆地里的空间结构，本工作是单条训练轨迹上的时序线性；ExPO 一类工作是在 SFT 与对齐 checkpoint 之间做跨阶段外推做分布匹配，本工作是在单个 RLVR 过程内部外推、目标是学新行为而非匹配既有分布。

### Q&A 要点

- **成本概念**：Q&A 中讲者估算，1.5B 模型在 H200 集群上 1000 个 global step 约需 50–60 小时，8000 步的资源消耗由此可见（字幕口径）。
- **logit 外推与 log-prob 外推**：本质相同，只差一层 softmax 归一化与温度，原理上可互换。
- **为什么拿 DeepScaleR 做分析对象**：参数配置与原工作对齐、排除配置干扰，且其在 AIME24 上约 0.4 的水平是当时公认的强基线；另外也用了 Skywork、DAPO 等数据集，线性与训练数据无关。
- **checkpoint 与系数怎么选**：起点可取初始模型或训练进度 20%–30% 处，不敏感；外推系数与任务相关，需要按目标任务调。
- **能不能一次外推到底**：不能。外推步长过大性能下降（倒 U 形），因为后期轨迹会积累偏差，必须靠周期性真实训练重新校准方向——这正是 RL-Extra 存在的原因。

## 可迁移

- **长 RL 训练的廉价探针**：把权重与探针 token 的 R² 监控做成训练旁路诊断——若前 20%–30% 步的轨迹已高度线性， $R^2$ 大于 0.7 ，可以先外推一个远期 checkpoint 做早期评测，用极低成本判断这条训练线值不值得跑完，适合 rollout 昂贵的 agentic RL 扫参。
- **RL-Extra 式预算分配**：真实梯度步只用于周期性校准方向、大步靠外推，这与 infra 侧「采样贵、计算便宜」的成本结构天然契合；可先在小模型 + 可验证奖励（数学/代码）上复现倒 U 形曲线，找到自己任务上的最优外推窗口再放大。
- **「调学习率不是外推」的判据**：当梯度与收敛方向的相关度很低时，加大步长只放大噪声；做 RL 训练调参时可先测这一相关度，再决定是加步长还是走外推/平均路线。

## 原文金句

> 「（RLVR）不会改变模型的固有核心能力，比如说这种基础的计算能力，而只是优化它的推理行为模式。」

> 「增大这种学习率，就相当于我们这个信号本来是有噪声的，然后你又放大了它的音量，这就只能让这个训练变得非常的不稳定。」
