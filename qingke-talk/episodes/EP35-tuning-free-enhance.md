## 一句话总结

讲者围绕「如何增强一个预训练好的扩散模型的采样过程」讲了两条互补路线：一是把初始噪声本身当作可学习对象，训练一个极小的 SVD 结构模型把随机高斯噪声改写成富含 prompt 语义的「golden noise」，即插即用地抬高生成质量；二是 Z-Sampling，在每一步去噪后用 inversion 把语义信息逐步注回 latent，利用去噪 CFG 与 inversion CFG 的差值实现「自我反思」式的轨迹优化，并进一步用图像扩散模型交替辅助视频扩散模型推理。

## 核心

### 引入：采样质量的一半写在初始噪声里

讲者的出发点是一个常见经验：同一个 prompt、不同随机种子采样出的高斯噪声，生成图质量差异很大，有的种子语义匹配明显更好。传统解法是反复试种子再挑最好的（讲授中称 seed selection 一类做法），但它有三条硬伤：只能拿到局部最优、要反复生成非常耗时、挑出的种子只对当前 prompt 和当前模型有效、没有泛化性。讲者由此把问题改写成一个机器学习问题：能不能训练一个模型，输入随机噪声和 prompt，输出一个更好的噪声？

### Golden Noise：先把定义立住

讲者强调一个反直觉的定义：在他们的工作里，golden noise 不是「对某个 prompt 生成质量最好的噪声」这么简单，而是**本身蕴含给定 prompt 语义信息的噪声**。这个定义后面 Z-Sampling 部分会给出机制解释：初始 latent 里的语义信息与 prompt 越相符，最终生成质量越高。如何往噪声里注入 prompt 语义？他们发现一个经验现象：把 latent 正常去噪一步、再用 DDIM inversion 加噪回去，得到的新 latent 就带上了 prompt 的语义信息，重新生成的图在文本描述与细节上强于标准采样。他们用两个实验坐实：纯随机高斯噪声训练的「噪声→prompt」分类器学不动（loss 与准确率基本不变），而用「先去噪再 inversion」得到的噪声训练，分类器 loss 持续下降、准确率持续上升；论文里另有理论证明（讲授未展开）。

数据管线随之确定：输入是随机初始噪声 + prompt，输出是用上述「去噪一步 + inversion」构造、再经人类偏好模型（HPS v2、PickScore 一类 reward model）筛选过的 golden noise——只保留确实生成出更高质量图的配对，保证数据集一致性。

### 模型架构：小模型只预测奇异值

难点在架构：扩散模型的噪声 latent 维度很高，让小模型直接预测整个噪声、或预测新旧噪声之差，拟合难度都太高。他们对收集到的噪声配对做 SVD 后发现一个关键结构：新旧噪声的奇异向量余弦相似度在 98% 以上，几乎只有奇异值不同。于是架构只做一件事：保留输入噪声的 $U$ 与 $V^T$ 不变，让小模型预测中间的奇异值矩阵，再经 SVD 逆变换得到预测噪声；另加一条残差预测分支补细节。prompt 信息通过一个 text embedding 以两个可学习系数（字幕中称 $\alpha$ 与 $\beta$ ，量级约 $10^{-4}$ ）注入——系数虽小，却是控制噪声里语义含量的关键旋钮，置零效果明显变差。训练只需单卡一到三小时（字幕口径）。

使用方式是即插即用：模型预测出 golden noise 后直接喂回原扩散管线，不改任何原 pipeline，因此可以和 ControlNet、LoRA 叠加，也可以和 DPO 一类偏好优化方法叠加（讲授口径）。

### Z-Sampling：轨迹侧的自我反思

第二篇工作把优化对象从起点换到整条轨迹。机制核心：扩散模型去噪时用的 CFG 与 inversion 时用的 CFG 之间存在差值，这个 gap 就是语义信息累积的来源。end-to-end 式的做法（整段去噪再整段 inversion 回去）步子太大、方向太随机，讲者类比于 batch size 为 1 的训练；他们改用 step-by-step 形式：去噪一步、inversion 注回一步、再正常推理，如此逐步累积语义、减小误差。消融结论有两条：必须全路径都用这种形式才最好；去噪 CFG 必须高于 inversion CFG，两者差值为零时生成结果与标准采样无异（副作用是差值过大时画面容易过饱和）。

### 视频扩展：让图像模型替视频模型「反思」

直接把 Z-Sampling 搬到视频扩散模型上效果不好（FVD 略升但 UMT score 变差，字幕口径），讲者给的原因是开源视频模型训练数据质量太低、反思时取不到好的语义信息。而把视频按帧看就是图像集合，图像扩散模型数据质量高得多，于是第三篇工作让图像扩散模型与视频扩散模型**交替**做 inversion 加噪与去噪：全用图像模型会丢时序信息、生成静止画面，交替则兼顾单帧质量与时序一致性。他们枚举了交替组合（字幕称共 $C$ 类组合逐一探究），IVIV 式交替（图像 inversion、视频 inversion、图像去噪、视频去噪再正常推理）效果最好，同样要全路径执行。他们还在做把这套范式迁移到 MaskGIT 一类掩码生成模型的工作（讲授口径）。

### Q&A 要点

- **多样性**：注入语义不会把生成过拟合到某个固定风格或 prompt，多样性与标准采样无异（讲者让提问者直接跑开源代码验证）。
- **分辨率限制**：当前开源只支持 $1024 \times 1024$ ；换分辨率要重收数据重训——收约 1 万到 1.5 万个噪声配对单卡需三四天，训练单卡三四小时（字幕口径）。
- **定位类比**：用法和 LoRA 一样即插即用，也能在 SD WebUI 里使用。

## 可迁移

- 「把采样起点当作可学习对象」是一个通用范式：任何由随机种子/初始状态驱动的生成或搜索过程（扩散采样、RL rollout 的初始状态分布、模拟退火初温），都可以用一个小模型先做「起点改写」再进主流程，且不改主流程本身——对推理 infra 而言这是成本最低的挂载点。
- SVD 观察的启发：当「好起点」与随机起点只差低维结构（奇异值）时，学习对象应降维到那个子空间；先对配对数据做结构分解再决定预测目标，比端到端硬拟合省算力一个量级。
- Z-Sampling 的 CFG 差值视角可迁移到任何带 inversion/重构的迭代过程：去噪与重构两条路径的条件强度差，就是信息注入率；做采样轨迹优化时先检查这条「差值通道」是否存在，比先设计复杂控制器更便宜。
