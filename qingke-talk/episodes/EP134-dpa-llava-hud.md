## 一句话总结

讲者连讲两件同组工作：DPA 把多模态对齐从目标大模型里解耦出来，在编码器侧先用一个带语言模块的小型 VLM（Perceiver VLM）把视觉特征逐层推向文本空间，再送进目标 LLM，使多模态训练对纯文本能力的灾难性遗忘大幅缓解（MATH500 从掉到 36.4 恢复到 54.2，字幕）；LLaVA-UHD v4 则把 token 压缩提前到 ViT 内部（第 6 层插入 compressor），配合切片编码与 pixel-shuffle MLP，在端到端 16 倍压缩下把视觉编码 FLOPs 砍掉一半以上而下游性能基本持平。共同主张：对齐与压缩都应尽量发生在视觉特征进入 LLM 之前。

## 核心

### 共同的问题设定

主流范式是 ViT + connector + LLM 两阶段训练，隐含假设是「ViT 特征经简单投影就足够接近语言空间」。讲者列了五个瓶颈（视觉 token 占比与平方开销、模态鸿沟、幻觉、动态推理弱、数据稀缺），本期只打前两个。关键证据是灾难性遗忘：Qwen3-4B 原生 MATH500 有 84.8 分，经过标准多模态训练后掉到 36.4 分（字幕）——LLM 的浅层被迫先干「把视觉对齐到文本空间」的活，深度预算被白白消耗。已有缓解方法多在数据层修补，不触及结构。

### DPA：把对齐解耦给一个懂语言的小模型

结构替换只有一处：把标准 ViT 编码器换成一个完整的小型 VLM（ViT + projection + 有深度的语言模块），取其最后一层的视觉 token 隐状态作为「已预对齐」的特征，再经 projection 送入目标 LLM。训练仍是 LLaVA 式两阶段（stage 1 只训两个 projection，stage 2 端到端指令微调），无辅助损失、无特殊技巧，工程上只是换了视觉编码器模块。

实验结论分三层：

1. **主结果**：在 4B 基座上多模态能力 +1.9 分、换到 32B 扩大到 +3 分（字幕），且通用、推理、感知全面领先而非单点；换到 Llama 系基座同样 +3 分量级（字幕），说明模态鸿沟与基座无关、单纯放大 LLM 解决不了。
2. **遗忘缓解**：同样训练下，标准结构 MATH500 掉到 36.4，DPA 恢复到 54.2（字幕），且训练数据里没有加任何额外文本数据；附录的参数更新分析显示 DPA 下目标 LLM 的更新更稀疏、对原有权重侵入更小。
3. **增益来源的消融（本期最扎实的一段）**：把 Perceiver VLM 从「完全未训练」到「两阶段训好」整条能力谱（自身均分 10.8 → 33，字幕）逐个接入，最终 DPA 模型成绩几乎不相关（53.1 vs 54.1，字幕）——增益不来自小模型本身强。去掉语言模块只留 ViT，增益只剩 0.7 分（完整结构约 3.4 分，字幕）；把语言模块权重随机初始化，成绩从 53 掉到 38.7（字幕）；换成参数量相当但无语言预训练的大 MLP，掉到 34.1（字幕）。结论：起作用的是语言预训练带来的「把视觉特征推向文本空间」的先验，不是参数量。

机理证据用模态鸿沟指标（视觉 token 与语言 token 的距离类指标，字幕作「MIMI 指标」）：在 Perceiver 内部随层加深鸿沟快速下降，特征进目标 LLM 之前已基本对齐；在 32B 上目标 LLM 内的鸿沟一开始就下降 77%（字幕）。成本：Perceiver 只多约 2% 参数与约 2% 训练计算，吞吐保持原模型的 98%（字幕），因为它只在 prefill / 编码阶段运行，逐 token 生成无额外开销。讲者强调 DPA 与数据混合类策略正交、可叠加。

### LLaVA-UHD v4：把压缩提前到 ViT 内部

背景：高分辨率成为默认后，ViT 后接压缩只能减轻 LLM 的负担，ViT 内部仍是随分辨率平方增长的开销。两个 pilot study 先行：

- **切片编码优于全局编码**：同 ViT、同 LLM、只换编码策略，切片在 4 倍 / 16 倍压缩率与不同数据规模下全面领先，平均 +0.5 到 +1.7 分（字幕），OCRBench 上 +3.6 到 +5.5 分（字幕）；换 ViT 骨干（SigLIP 2 → MoonViT）与更高分辨率下结论不变。归因：切片保局部性，避免固定算力下局部与全局注意力互相干扰。
- **pixel-shuffle + MLP 优于 query 型 resampler**：前者在所有数据量与压缩率下领先；resampler 参数更多却更差，因为 query token 无空间相关性、压完丢空间结构。

正式结构：在切片编码 + ViT 后 pixel-shuffle MLP 的基础上，于 ViT 第 6 层插入内部 compressor——先做 2×2 窗口自注意力让相邻 token 交换信息，再 pixel-shuffle 下采样（内部先压 4 倍），ViT 后再压 4 倍，端到端 16 倍。插入遵循三条设计原则：压缩必须真减 ViT 自身计算（提前到中间层）、插入越早越好、不能破坏预训练表示流形——实现手法是 compressor 的注意力 / FFN / norm 权重全部复用插入点前一层 transformer block 的已有参数初始化。插入层深消融：第 3 层太早（语义未成形，性能掉到 39.4 分，字幕），第 6 层最优，第 9 / 15 层性能不更好且计算量更大。主结果：与「压缩全放 ViT 外」的同压缩率 baseline 相比，八个基准平均性能损失仅约 0.29 分、差距维持在 ±0.8 内（字幕），视觉编码计算量从 3500+ GFLOPs 降到 1500+ GFLOPs（字幕），减半以上；消融显示 average pooling 明显掉点，window attention + pixel-shuffle + 参数复用的组合最好，甚至超过 baseline。

### 趋势与 Q&A

讲者列了四个趋势（理解生成统一、感知到推理、具身智能、高效化与端侧），自陈两件工作分别服务于「对齐高效化」与「视觉编码高效化」。Q&A 里几个值得记的回答：用目标 LLM 的前几层充当 Perceiver 不行——鸿沟要到约 2/3 深度后才降到初始的一半左右，他们取尽可能靠后的隐状态作输出；压缩后 RoPE 无需特殊处理，pixel-shuffle 保相对位置、直接用 MMRoPE（字幕口径）；ViT 内部压缩此前并非无人做，但普遍掉点，本工作的点在于证明「提前到内部可以不掉点」；高分辨率小目标被空间压缩吞掉是公认潜在问题，语义引导压缩可能更好，但他们还没做对照实验。

## 可迁移

- 「对齐负担前置」是一个可复用的结构判据：当下游大模型出现能力被上游适配吃掉的迹象（此处是文本能力遗忘），先量化模态 / 表示鸿沟随深度的变化，再决定把对齐模块放在编码器侧还是模型内——而不是先堆数据混合修补。
- 内部模块插入的初始化纪律：在预训练 ViT 中段插入新模块时，用相邻层已有参数复用初始化、保持表示流形连续，是「插进去不掉点」的关键工程项；可迁移到一切在预训练骨干中段加模块的场景。
- 压缩选型判据：保留空间相对位置的局部压缩（pixel-shuffle 类）优于无空间先验的 query 重采样，且参数量不是决定因素——评测生成 / 理解模型的 token 压缩方案时可直接套用。
