## 一句话总结

LA4VLA 先做诊断实验证明：标准 VLA 预训练里动作其实没有被语言锚住，而是被密集的视觉信号带着走（换掉图像，动作就跟着图像暗示的方向跑）。它的做法是把「语言如何约束动作」先从联合训练里拆出来单独学一遍——构建无视觉的 LA33K 数据集（原子动作指令 + 本体状态 → 动作），先做 vision-agnostic 的 LA 预训练学一个可复用的语言条件动作先验，再接回带视觉的 VLA 预训练。仿真、跨架构、真机与视觉扰动四组实验一致显示：LA 单独预训练就强于带视觉的 VLA 预训练，两者结合（先后或混合）进一步提升，且动作在表示空间里按文本聚成簇。

## 核心

### 背景/问题：视觉信号从三个层面压过语言信号

讲者把「语言为什么约束不住动作」拆成三层：

1. **数据层密度不对称**。一条轨迹里有成百上千帧图像–动作对（字幕口径：平均约 287 帧/轨迹），却只有一条从头到尾不变的高层指令；即使加 subtask 标注，粒度仍偏粗，语言与局部动作对不齐。
2. **输入层 token 不对称**。图像被编码成数百个 token，语言 token 少一到两个数量级，架构上模型更容易盯着视觉 token 的变化走。
3. **行为层 shortcut**。换了 prompt 模型照样按当前场景做原来的事；视觉一变（指令不变），动作就切换到另一个任务。语言退化成任务一/任务二式的条件 label，而不是对动作的约束。

核心判词：标准 VLA 预训练让策略学到的是「看到什么就怎么动」，而不是「语言如何约束动作」。

### 诊断实验：把视觉拿掉/换掉，动作还听不听语言

固定语言指令与机器人状态不变，只动视觉输入，四种条件对照：

- **标准配对**：指令与原本配对的视觉观察一致；
- **遮挡视觉**：把图像遮住；
- **错配视觉**：同场景、但与当前指令不匹配的观察；
- **冲突视觉**：把图像换成来自相反运动方向轨迹的观察（图像暗示与指令直接打架）。

四个指标（字幕口径，约 100 个方向样本统计）：方向对齐率（末端位移落在指令方向的比例，0.5 为随机、低于 0.5 为更常落到反方向）、方向一致性（预测末端位移与真实末端位移的余弦相似度）、不同指令间的可分性、轮廓系数（同指令样本是否更靠近）。

定性结果很直白：遮住图，轨迹完全散掉、分不清方向；换成没见过的图，动作走成一个偏执方向；冲突条件下，指令明明说往 Z 轴正向走，模型却跟着图像往负向走。定量上，视觉一旦移除/错配/冲突，四个指标全面大幅下降。讲者的结论是：标准预训练下的「听指令」是一种表面对齐——训练与推理配得越齐越显得听话，视觉一冲突就露馅，因为动作根本没绑定在语言上。

### 方法：先学「该怎么动」，再学「目标在哪」

LA4VLA 的主张（借讲者的人类类比）：人闭着眼也能伸右手、推门、放东西，本体感知不需要视觉。视觉主要负责「目标在哪里」，语言–动作先验负责「该怎么动」，两者可以分开学：

1. **LA 预训练（无视觉）**：输入语言指令与本体状态，预测动作，显式学语言条件的动作先验。注意不是只训动作头（DiT/flow-matching 头），而是 VLM 主干与动作头一起训（字幕口径）。
2. **接回 VLA 预训练**：在 LA 先验之上再引入视觉做正常的 VLA 训练与下游微调。

讲者用的比喻是先让机器人「对自己的身体有个认识」，再引入视觉。

### 数据：LA33K 的七步构建流水线

1. 取原始 VLA 数据（字幕口径：约 9500 条轨迹）；
2. 关键帧检测切分（关注静止段与夹爪开合跳变，作为原子动作边界）；
3. 写原子动作词表（当前 12 类，如 lower / push / lift / grasp / release 等）；
4. 带词表提示 VLM（字幕口径：Qwen3-VL-Plus）生成候选切分片段与指令（约 5.6 万条）；
5. 人工逐条检验，过滤掉一切需要视觉才能判别的信息（颜色、物体名等不进入指令文本，指令保证 vision-agnostic）；
6. 清洗后保留 33K 条 episode，是原始轨迹数的 3.46 倍；
7. 平均长度从约 287 帧压到约 46 帧——把稀疏的任务级语言监督换成密集、局部对齐的语言–动作监督。

另备带视觉版 LA33K-V（片段、指令、状态、动作、预训练步数全同，唯一变量是视觉在不在），专为证明「收益来自去视觉」而做。数据集与 StarVLA checkpoint 已开源（HuggingFace 有下载，字幕口径）。

### 实验：五种预训练组合的完整对照（同模型同超参）

主模型为 1B 级 VLA（backbone InternVL3-1B + flow matching 动作头，字幕口径），下游微调流程完全一致，五种组合：

- **Base**：无预训练，直接微调；
- **VLA**：在 LA33K-V 上带视觉预训练；
- **LA**：在 LA33K 上无视觉预训练；
- **LA→VLA**：先后两阶段；
- **MixPT**：两份数据单阶段混合（采样 1:1，字幕 Q&A 口径）。

仿真主结果（Meta-World，字幕口径）：Base 69 → VLA 79 → LA 83，LA 单独预训练即超过带视觉的 VLA 预训练；LA→VLA 与 MixPT 再进一步（讲者开场给的宏观口径：最佳融合方案在 Meta-World 相对 baseline +17.8%）。LIBERO 趋势相同（LA > VLA，结合更好；LA→VLA 与 MixPT 在不同 benchmark 上轮流最优）。

其余三组验证（均为字幕口径）：

- **跨架构**：同一套 LA 预训练搬到 StarVLA，Meta-World 58.4% → 69.9%（+11.52），LIBERO 同样提升——讲者强调这是监督信号层面的收益，不是某个模型结构的专属技巧；
- **真机**：三类「同场景、靠指令区分动作」的任务，LA > VLA、结合更高（开场口径：最佳融合方案相对 baseline +45%）；
- **视觉扰动**：给训练图像加高斯噪声，无预训练最低，MixPT > LA > VLA 依次提高；且 LA 预训练后无视觉也能跟语言走，表示可视化里动作按文本聚成簇，而普通 VLA 的动作按 state 零散分布。

### 结论/观点（讲者明确表达的判断）

1. 模态不对称真实存在：密集视觉信号会稀释语言–动作监督，多篇同期工作也在论证同一现象。
2. 语言–动作监督可以被单独抽出来，先学可复用、可跨场景跨任务的动作先验，再与 VLA 监督互补（先后或混合都成立）。
3. 增益的主要来源是本体感知：LA 阶段没有视觉 shortcut，模型对原子动作本身更熟（Q&A 口径：真机上抓、放等原子动作做得明显更好）。
4. 局限（讲者自列）：LA33K 只从约 9000 余条原始轨迹切出；视觉移除用黑图替代，是否有更好的移除方式未尝试；下一步是 scale LA 数据量，验证「先验随数据量继续变强」这条曲线。

## 可迁移

- **对 post-training 数据构建**：LA33K 的做法本质是「把稀疏的 episode 级监督切成密集的原子级监督，并人为剥离不需要的模态通道」。迁移到 LLM post-training：当某个监督信号（如系统提示、工具 schema）被高频信号（长上下文、代码块）稀释时，可以考虑先单独训一遍「信号→行为」的窄任务，再合回联合训练，而不是指望联合训练自己学会配比。
- **诊断先行的方法论**：这篇最值得借的是诊断实验设计——固定其他一切、只扰动一个模态，看行为跟谁走。对自己的 RL/agent 评测同理：怀疑模型在靠 shortcut（比如靠工具返回格式而非语义）时，做「换掉/遮掉该通道」的反事实探针，比看 benchmark 分数更能定位问题。
- **Infra 视角**：LA 与 VLA 两阶段是纯粹的训练配方（同模型、同超参、同数据片段，唯一变量是视觉在不在），复现成本低；作者把 StarVLA checkpoint 直接开源，适合拿来做小规模 A/B 验证「先验式预训练」在自己任务上的收益。

## 疑问 / 下一步

- LA33K 只有 33K 条、原始轨迹约 9000 条，讲者说下一步要 scale——LA 先验的 scaling 曲线（数据量 vs 下游收益）是全篇最关键的未验证假设，值得等后续版本。
- 「视觉移除用黑图替代」是讲者自列的局限：黑图本身也是一种分布（模型可能学到「黑图→只听语言」的条件开关），到真机遇到真实视觉时这个开关是否还成立，真机实验部分回答了但规模有限。
- 零样本泛化只在方向/原子指令层面验证过（Q&A 口径），复杂空间关系指令在 LA 阶段被构造性排除了（指令里不允许出现需要视觉的指代），这条边界在向更复杂任务推广时需要重新处理。
