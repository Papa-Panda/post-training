2一句话总结

高深远串讲了团队构建「通用可泛化驾驶世界模型」的两步工作：① GenAD 配 OpenDV 数据集——从 YouTube 采集 2000 多小时、横跨 40 多个国家 200 多个城市的驾驶视频（比 nuScenes 大 370 倍），用 VLM 自动标注 + 自动滤除 + 驾驶行为分类清洗成高质量训练集；再把 Stable Video Diffusion 从「image-to-video 生成」改造为真正的未来预测模型（固定条件帧为视频第一帧 + 多帧 context 提供动力学先验 + dynamics-aware 与高频两类辅助损失），实现长时序一致的 roll out。② Vista 在此基础上补齐四件事：统一编码的多模态 action control（command、goal point、轨迹、速度/方向盘角等，类 ControlNet 注入）、低到高分辨率的多阶段训练 + LoRA 微调以低成本学控制能力、用「预测不确定性即 reward」的免监督判定（在人类安全驾驶视频上训练的世界模型，对不合理 action 的预测方差会变大，可直接当奖励函数、且排序比 L2 误差更合理）、以及 15 秒级的高分辨率长视频预测。小结中最有价值的是讲者对局限的坦率：推理慢（A100 上 12.5 秒视频要 1 分多钟）、command/goal point 控制弱、红绿灯规则与物理理解仍有硬伤；未来方向是把视频世界模型与 3D 重建（Gaussian Splatting 一类）结合，让未来预测能直接算出可用于决策的 cost。

3核心

世界模型为什么值得为自动驾驶认真做

讲者用 LeCun 2022 年 position paper 的四模块框图（感知、action、world model、cost）定场：世界模型是「给当前状态与 action，预测下一个状态」的状态转移函数。放进自动驾驶开发闭环，它同时治四个瓶颈：数据采集（真人真车、费时费力、有安全问题、场景受限）、训练（固定 data log，无法捕捉「换一种策略走这条路会怎样」的多模态行为、无法反事实推进）、评测（真车路测难以 scale）、部署（可套 model predictive control，用预测提前避开灾难性后果）。

但讲者随即划了两个判据，把「视频生成」与「世界模型」分开：Sora 这类 text-to-video 模型对驾驶不够用——文本表达不了决策过程中的 action；而现有驾驶世界模型（DriveDreamer 等）共同的四个局限决定了新一代世界模型的目标函数：①泛化差（nuScenes 只有 5 小时、只含新加坡与波士顿；DriveDreamer 换一个中国城市的样例直接失效）、②表征弱（保真度低、有 artifacts，分辨率与帧率低）、③action control 单一且没人验证过「换个新场景控制还管不管用」、④只谈构建不谈应用（缺 reward、缺闭环）。GenAD/Vista 每一项技术基本都能映射回这四条中的一条。

GenAD 与 OpenDV：先解决「数据从哪来」

讲者把泛化问题的根源定位在数据：nuScenes 太小，于是团队去 YouTube 采——「YouTube 是一个无穷无尽的数据来源」。OpenDV（字幕口径）规模：2000 多个小时、40 多个国家、200 多个城市，每段视频半小时到三四个小时，天然就是一个长视频生成数据集（讲者笑说「当时采这个数据的时候，并不知道有 Sora 会出来」）。

但原始 YouTube 数据不能直接下：「YouTube 上有非常多的脏乱的数据」，所以配了一条完整的处理链路：

  1. 选高质量视频 → 下载；
  2. 用 vision-language model 标注 context（场景中的车、街道、天气等）；
  3. 按关键词自动滤除（全黑、模糊、广告弹出等）；
  4. 训一个视频分类模型标注自车行为（左转/右转/变道等）。

最终得到带 context 自然语言描述与自车行为自然语言标注的多模态数据集，已公开（含处理流程、下载链接与标注）。这套「VLM 标注 + 规则滤除 + 行为分类」的 web-video 清洗流水线，是本篇最可移植的工程部分。

把 SVD 改造成未来预测模型：四个技术点

GenAD 的出发点是 Stable Video Diffusion（SVD），但讲者强调 SVD 是 image-to-video 生成模型而不是预测模型：生成视频的第一帧与条件帧并不一致，长 roll out 时「风格和内容会产生非常剧烈的跳变」。GenAD 的改造逻辑链：

  • 固定条件帧为待生成视频的第一帧、关掉 noise augmentation：模型学会从这一帧出发预测未来，content 一致；
  • 多帧 context（上一段预测的最后几帧）作条件：只给一帧时模型无从推断速度/方向等动力学信息，片段之间运动接不上；context 帧提供「dynamic prior」，用的帧越多，与 ground truth 的运动越一致——这条讲者用广告牌的运动一致性可视化实证；
  • Dynamics-aware 辅助损失：用「预测帧间差与真值帧间差之差」高亮运动剧烈、难以预测的区域，在标准 diffusion loss 之外对该位置加权——讲者举的两个例子是高速上「前面那辆车停着不动」（未建模的运动）与右转时「远处的树木应往左移动却纹丝不动」（ego 运动耦合）；加完这两个症状都消失；
  • 高频辅助损失：运动物体的边缘模糊/破碎是高频信息丢失，把预测特征图做频域变换、高通滤出高频、只对高频部分加监督后，卡车与白车的轮廓在运动中保持锐利完整。

结果是 SVD 只能生成 2–3 秒，GenAD 可以不断 roll out 出长视频。讲者对 GenAD 保真度的论述没有停留在定性：GenAD 与 Vista 在 FID/FVD 上均优于既有驾驶世界模型，并在与 I2VGen-XL（阿里）、DynamicCrafter（腾讯）、SVD（Stability AI）的主流视频生成模型 human evaluation 中，视觉质量与运动合理性「都要好」。

Vista：补齐控制、reward 与长时高清

Vista（NeurIPS 2024）是在 GenAD 基础上的系统升级，四个新增点：

  1. 统一的多模态 action control：把 high-level command、goal point、轨迹、速度、方向盘角等「所有跟驾驶相关的 action」统一编码，以类 ControlNet 方式注入；使用时「只需要用一种」即可独立控制（与 GenAD 阶段多为单模态形成对比）。
  2. 低成本学控制的两段式训练：第一阶段只在未标注的 YouTube 数据上训练（学泛化与真实性）；第二阶段把 U-Net 主干固定、在 nuScenes 上学多模态 action 控制、同时混入 YouTube 数据保持泛化；再配多阶段分辨率策略（低分辨率多 iteration 快速学会控制、高分辨率少量微调）+ LoRA 微调 + action 独立约束加速（细节见论文）。
  3. 不确定性即 reward（本篇概念上最亮的一点）：世界模型在人类驾驶视频上训练，「人类基本上都是安全开车」；拿不合理的 action 去条件时，预测的不确定性（方差）会升高。于是直接把「该 action 下预测的方差」当作 reward——无需参考真实轨迹、无需监督，还能在任何场景下执行。讲者用一个代表性 case 对比 L2 误差的荒谬：开阔路面上向前加速直行，L2 说错（与 ground truth 轨迹不一致）、reward 说对（向前多开没有问题）；冲向旁边，L2 说近（与原轨迹差得不远）、reward 说错（危险）。这个排序合理性正是「reward 作为决策评价函数」区别于「轨迹拟合误差」的地方。Q&A 中讲者补充：uncertainty 不需要把视频生成完，「只需要做几步 denoise」即可估出，效率高；也未被用作 loss 训 policy，先作 metric 用。
  4. 长时高清预测：未见过的新环境下仍可做高分辨率、高帧率预测，最长可续到 15 秒（字幕口径，Q&A 确认「目前我们最长可以做到 15 秒的生成」）。

外部认可（讲者口径）：模型公开后收到了 HuggingFace CEO、Comma AI CTO 的评价；人形机器人公司 1X Technologies 与团队多次交流、想把 Vista 用到室内人形机器人数据上；腾讯的新工作把 Vista 作为自动驾驶赛道的 baseline 与可灵、Luma 等商业模型对比。

小结与展望：讲者对局限的坦率清单

讲者没有用成绩收尾，而是先列问题（这部分对后来者最有用）：

  • 推理开销大：生成 12.5 秒视频在 A100 上仍需 1 分多钟，车端在线使用「现在不行」；
  • action control 不完美且模态间不均衡：轨迹控制最强，goal point 与 command 弱——归因于数据分布（nuScenes 大多直行、command 分布极偏；goal point 取前视图二维坐标，很多 sample 的点根本不在前视图内，是无效样本）；解法是补更多丰富 action 标注的数据集 + 训练时对 action 分布 re-balance（resample 转弯 command）；
  • 物理与规则理解仍有硬伤：车会「分裂」（不理解物体组成）、无 action 控制时面对红灯也会往前开、长视频质量随时间的下降与细节平滑；
  • action control 不精准的一个结构性原因：真实驾驶视频「有迹可循」——模型不看 action 也能凭迹象猜出接下来怎么开，这与「反事实推理」之间是张力；讲者举的正面涌现例子同样迷人：强行让自车执行危险的 goal point 时，旁边正在过马路的车会停下来让行——即其他 agent 会根据自车行为做出反应，这是 closed-loop simulation 可行的前提。

展望押注在 3D：视频世界模型胜在可扩展性（能在互联网视频上训练）与因果/反事实推理，但输出只是 2D 像素，「没有提供非常直接的信息用于决策」；Gaussian Splatting 类重建能给出显式 3D 表征，可以直接算「自车有没有跟其他车撞在一起」的 cost。讲者认为的 promising 方向是让世界模型既保有视频路线的泛化与因果能力，又能预测出带 3D 信息的未来、直接服务于 cost 计算与决策。对 latent world model 的评价同样务实：Vista 本身就在 latent space 预测，pixel 输出只是为了提供监督信号；真应用时「可能不需要重建出整个视频，只要预测出未来状态的一些表征」就够了。

Q&A 精选

  • 训练资源（字幕口径）：第一阶段 128 张卡 + 第二阶段 8 张卡；两个阶段共两周（约 8 天 + 7 天，讲者自述「我中途有中断几次，然后进行继续训练」）。经验判词是「batch size 不是特别重要」「主要是靠叠 iteration」——少些卡训久也能得到类似效果。GenAD/Vista 全程以 SVD 预训练为出发点；Q&A 中明确建议从预训练开始（市面上还没有现成的、带世界模型功能的视频模型可买）。
  • 帧率（采样频率）影响：训练数据默认 10 Hz 采样；预测固定帧数时采样越稀、时间跨度越长、难度越大——「你预测 25 帧、采 2 Hz，这个其实就更长了」。
  • 可控性增强：一是高维 action + 数据多样性/重平衡，二是附录里的方案——把 action 信号单独拆出来做多重 classifier-free guidance（代价是计算倍增）。
  • uncertainty 无监督为什么准？ 因为不安全 action 与人类数据的组合是 out-of-distribution，模型在 OOD 输入上方差自然变大；可调项包括 denoise 步数（要调）。
  • Vista 生成的数据能训端到端模型吗？ 可以生成，但 Vista 不提供 3D 监督信号；若下游需要 3D 信息则不行。另一条互补路线是 bounding box / layout 条件生成，直接服务感知训练数据，与 action 条件是「两条不同的技术路线」。
  • 多视角？ 现在没做（为了保泛化覆盖）；可能路线是单视角预测再 adapt 到多视角。

5可迁移

  • 「互联网视频 + VLM 自动标注 + 规则滤除 + 行为分类」是一条可整段搬运的数据流水线：任何需要大规模真实世界视频训练的团队（机器人、具身、驾驶仿真）都可以复用——关键是把「脏数据滤除」做成关键词规则 + 学到的行为分类，而不是人工筛。
  • 「把生成模型改造为预测模型」的判据可泛化到一切 sim2real 评估：条件一致性（第一帧锚定）、动力学先验（多帧 context）、针对运动区域与高频的辅助监督——这三个改造正对应「自回归 roll out 的误差从哪来」；把「生成」与「预测」分开的思考方式也适用于任何把 diffusion 视频模型当环境模型的场景。
  • 「不确定性即 reward」是 world-model 派给 RL 的一个低成本接口：在只有人类（近似最优行为）视频、无显式奖励标注时，用预测方差做 action 排序，比轨迹 L2 更贴决策语义；讲者在 Q&A 中的补充同样关键——估方差「只需几步 denoise」，这让它在闭环评测里成本可控。这个接口与「用世界模型给 policy 提供 dense reward/评测」的思路直接对应，可迁移到机器人策略评测。
  • 两段式训练（大规模无标注学泛化 + 小规模有标注学控制、主干冻结 + LoRA）是典型的「能力解耦」部署范式——先保能力、再补接口，迁移到任何基础模型后训练中都是省钱的办法（讲者甚至强调 iteration 远比卡数重要，这条经验对 diffusion 类训练尤其实用）。
  • 诚实的局限清单本身是可迁移的方法论：command/goal point 控制弱 → 归因到 action 分布偏斜与无效样本；「视频有迹可循」→ 指出反事实能力与可预测性的内在张力——这种「失败模式先于新功能」的分析顺序，正是把世界模型从 demo 推向可用系统的路径。

7原文金句

「（世界模型）本质上来说它是一个充当一个状态转移的功能：我给定现在这个状态，然后给定他要做的这个 action，world model 它就是能根据这些条件，预测出下一个状态。」

「（在加速直行时）这个 L2 error 因为跟 ground truth 的轨迹不太一样，所以它就会变得很大……但是我们这个 reward 就能正确地判断出来：你往前多开一点也是可以的，但是往旁边冲上去，它的 reward 应该是要低一点。」

「他其实就可以为 closed-loop simulation 提供一种可能性。」（谈其他车辆会根据自车行为做出反应时）
