## 一句话总结

视频世界动作模型（WAM）为了给策略「预见未来」要逐像素生成未来视频，慢且贵（LingBot-VA 单次推理 4,482 ms）；LaWAM 改在冻结视觉编码器的隐空间里预测一个与下一段动作相关的「隐空间视觉子目标」—— 把隐动作模型（LAM）原本被丢弃的前向解码器扶正为隐空间世界模型 LaWM，策略先预测隐动作、再由 LaWM 展开成子目标、最后动作专家据此生成动作块。结果是 2.3B 参数、每动作块 187 ms，在 LIBERO 拿到 98.6% 平均成功率、RoboTwin 2.0 拿到 91.22%、真机三任务平均 90.0%，端到端延迟最高比像素 WAM 低 24 倍。

## 核心

1. **背景/问题**：VLA 只有语义理解、没有「动作会把场景推成什么样」的显式预见；WAM 用预测的未来观测补这一课，但像素路线有三笔账算不过来：把大量建模容量花在纹理光照等与控制无关的像素合成上；迭代式视频生成带来高延迟（论文同口径实测：LingBot-VA 4,482 ms、Motus 3,231 ms，而普通 VLA π₀.₅ 只要 220 ms）；生成出的未来还得「看起来合理」而非「对下一段动作有用」。论文的判断是：控制真正需要的未来，只是物体将如何移动、接触区域在哪、当前动作会把场景推向什么状态——这些信息主要在空间结构里，不在像素里。

2. **方法/设计**：全部在冻结视觉基础模型（DINOv3）的特征空间里工作。记当前观测的特征为 $u$ ，未来观测特征为 $u_T$ 。第一阶段先训一个隐动作模型：逆向动力学编码器从一对当前/未来特征里推断隐动作 $z$ ，前向解码器再据当前特征与隐动作预测未来特征：

$$z \sim q_\phi(z \mid u, u_T), \qquad \tilde{u}_T = \mathrm{LaWM}_\omega(u, z)$$

以往的隐动作工作（LAPA、UniVLA 等）把这个解码器只当预训练的辅助件、训完就扔；LaWAM 的关键一步是把解码器保留下来扶正为 **LaWM**（Latent World Model）—— 它已经学会「给一个抽象动作意图，在当前场景里展开成未来的视觉状态」，正好是策略缺的那块。训练目标包括未来特征预测误差、KL 正则，以及一个轻量的末端执行器状态预测辅助损失（让隐动作更偏具身运动、少被纯外观变化带偏）。部署时真实未来还没发生，链条变成三步：策略先验预测隐动作，LaWM 解码出子目标，动作专家生成动作块：

$$p(a_{1:T}, \hat{u}_T, \hat{z} \mid o, l) = p_\theta(\hat{z} \mid o, l) \, p_\omega(\hat{u}_T \mid u, \hat{z}) \, p_\eta(a_{1:T} \mid o, l, u, \hat{u}_T)$$

第二阶段把 LaWM 接进策略时有两个关键件：一是**隐动作蒸馏**（latent-action distillation），用第一阶段 LAM 的后验直接监督策略先验，让策略学会稳定地「驱动」LaWM；二是**知识隔离**（knowledge insulation），策略训练时不让动作专家的梯度回流破坏 LaWM 已学到的场景变化规律。动作专家是 Alternate-DiT 结构，条件是当前上下文加 LaWM 给出的子目标。预训练数据约 3,000 小时机器人视频 + 1,500 小时第一视角人类视频；人类视频只经由 LaWM 的动力学先验进入系统，策略整合阶段只用带语言指令的机器人轨迹—— 人手的动作意图先在隐空间变成「视觉状态转移」，再由 LaWM 结合机器人当前看到的场景展开，绕开了「人手关节 → 机器人关节」的硬翻译。
3. **实验/实战**：仿真两条线。LIBERO 四套件（每任务 50 次试验）：LaWAM 平均 98.6%（Long 97.0 / Goal 98.4 / Object 99.6 / Spatial 99.4），压过像素 WAM 里最强的 Cosmos-Policy 与 LingBot-VA（均 98.5%）和 π₀.₅（96.9%）；隐动作基线 LAPA 只有 65.7%，差距说明隐动作单独当接口不够、展开成空间结构化的子目标才是增益来源。延迟（每动作块、模型侧墙钟）：LaWAM 187 ms，π₀.₅ 220 ms，Fast-WAM 486 ms，Cosmos-Policy 1,413 ms，LingBot-VA 4,482 ms—— LaWAM 比最慢的像素 WAM 快约 24 倍；LaWM 只有 230M 参数，相比 5B 的 WAN 视频底座省约 95% 世界建模参数，全模型 2.3B。RoboTwin 2.0（50 个双臂任务、每任务 100 次）：clean 92.64% / random 89.80%（平均 91.22%），clean 略高于 Fast-WAM 的 91.98/90.52，稳住双臂协同。真机三任务（每任务 30 次，含分布外初始位形）：抓放 93.3%、开抽屉 86.7%、折毛巾 90.0%，平均 90.0% 对 π₀.₅ 的 83.3%；折毛巾上差距最戏剧—— LingBot-VA 因生成延迟「机器人停下来等视频、布料却不等」，成功率 0.0%。动力学分析：把同一段隐动作放到没见过的场景与本体里开环展开，LaWM 能给出连贯的隐空间演化—— 隐动作是本体无关的视觉转移，LaWM 负责把它落回当前本体的场景里。消融（LIBERO）：去掉 LaWM 掉得最狠（尤其 LIBERO-Long），去掉隐动作蒸馏也明显掉，两者（知识隔离 + 蒸馏）一起去掉更差—— 结论是子目标必须「既能被对齐的隐动作驱动、又要免受动作梯度污染」。
4. **结论/观点**（论文口径，非讲者原话）：给策略的未来不必是像素级的，只需是动作相关的；隐动作负责跨本体表达抽象转移、LaWM 负责把转移落回当前场景，两件合起来构成「人类视频 → 机器人动作」可复用的中间层。作者自陈两点局限：当前设定最适合相机相对固定的操作任务，相机自身运动主导画面变化时（第一视角抖动、大视角切换）隐动作空间学不连贯，这限制了它在人形/移动机器人上的直接使用；细粒度可变形物体动力学（如折毛巾中微妙的布料形变）在现训练混合里样本太少，LaWM 建模不可靠，下一步是扩数据与模型容量。

## 可迁移（放到 RL 训练 / 数据构造 / 评测框架）

- **「未来」给策略时只给任务相关的压缩表示**：LaWAM 把未来从像素视频换成隐空间子目标后，延迟降一个数量级而成功率不降。迁移到 agent/RL：任何「先想象再行动」的环节（rollout 预演、规划器给执行器的中间表示），先问表示里哪些维度是决策真正要读的，把纹理级细节从接口里删掉再谈模型大小；对 coding-agent 来说，类似地，给执行步的子目标应是结构化的状态差分而非整段重演的轨迹文本。
- **保留并扶正「辅助模块」当推理期组件**：LAM 的解码器在前人工作里训完即弃，LaWAM 把它变成世界模型本体。迁移视角：预训练里的辅助头（逆动力学、未来预测、价值预测）在后训练阶段未必该扔——先检查它是否已经学到了可调用的环境规律，再决定是当特征、当教师还是当在线模块。
- **知识隔离 + 蒸馏的接口对齐套路**：让策略驱动一个冻结的先验模块时，LaWAM 用「后验蒸馏教接口、梯度隔离护模块」两件套防双输。这正是 post-training 里常见的失败模式（下游微调把预训练表征训坏）的直接对应解法，可搬运到任何 frozen-backbone + adapter 的微调管线。
- **延迟要进评测口径**：折毛巾上 0% 与 90% 的差距不是模型能力而是「等视频生成时布料不等你」。评测动态任务时应把每步决策延迟与任务时间常数一起报告，慢推理在长时程任务里会以成功率的形式还账。

## 疑问 / 下一步

- **讲者现场口径待回填**：本期字幕被串台堵死，陈佳磊在讲授里如何拆两阶段训练的工程细节（隐动作维度、LaWM 的具体结构、Alternate-DiT 与子目标的融合方式）、AMA 里对「移动相机」局限的展开，都只能等回放字幕可得后修订本篇（论文 Appendix C 有部分实现细节，可先查）。
- 隐动作空间本身的可解释性与容量：隐动作维度、码本/连续的选择对跨本体迁移的影响，论文正文着墨有限；「同一隐动作多本体展开」的定性结果漂亮，但缺定量指标（如展开轨迹与真实未来的特征距离）。
- RoboTwin random 设定（89.80%）仍略低于 Fast-WAM 与 LingBot-VA 的 random 口径（90.52% / 90.92%），clean 领先、random 微输—— 隐空间子目标对域随机化的鲁棒性是否弱于像素路线，值得在后续版本里盯。
- 与同期「像素子目标」路线（如 π₀.₇ 用独立像素模型产子目标）的取舍：LaWAM 赌的是隐空间够表达动作相关动态，这个赌在需要精细接触几何的任务上（插拔、装配）的边界未测。
