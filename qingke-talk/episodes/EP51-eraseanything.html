2一句话总结

EraseAnything 是第一个在 Flux 这类 Rectified Flow Transformer 上验证有效的概念擦除方法：它只在双流块（dual-stream block）上挂 LoRA，用注意力图定位待擦概念、用反向自对比损失把目标概念在语义空间里推向无关概念并远离其近义词，再用双层优化把「擦除」与「保留无关概念」分开交替训练，从而能擦掉实体、抽象概念乃至「握手」这类关系，且擦得干净、其他概念基本不受损。

3核心

1. 背景：架构换代后，旧擦除方法在 Flux 上集体失效

概念擦除要解决的是扩散模型的安全/可控问题：模型会生成不宜内容（讲者举例 NSFW 图像），需要让它「忘掉」指定概念。2023 年 SD 出现后不久这个方向就热起来，代表作 CA、ESD（ICCV 2023）以及 UCE、EAP 等都建立在 SD 1.x 的 UNet + CLIP 文本编码架构上。

问题在于基座已经换代：Flux（黑森林实验室出品）用 T5 做文本编码、用 RoPE 旋转位置编码、图像与文本走 dual-stream block 分开处理再拼接、采样器换成 Rectified Flow。讲者把旧方法直接搬到 Flux 上复现的结果是：擦裸体只补出下半身、上半身仍裸（ESD）；擦是擦了但人物外观全毁（UCE）；EAP 干脆擦不掉。而 EraseAnything 在同一批案例上能擦掉裸体、梵高风格、蜘蛛侠的西服，且整体一致性保持得不错。讲者的结论是：架构变化不是小事，方法必须针对新架构重做，他们是第一个在 Flux 上验证这件事的人。

2. 方法定位：只改 dual-stream block，且是试出来的

Flux 没有显式的 cross-attention 层——过去大家习惯改的那一层不存在了。讲者的实验把作用点锁定在文本与图像特征混合的第一个阶段即 dual-stream block，只在那里训练 LoRA。他很坦白这一步的来源：「完全是根据经验，一个一个试出来……先有假设，验证 OK 就继续往下走」，并感慨做大模型研究的假设与效果很少天生相符，「所以大家要多做实验」。实验基座选 Flux 的开源版本 schnell 与 dev（pro 闭源改不了权重）。

3. 方法组件一：注意力定位擦除

第一个组件回答「概念存在于哪里」。用 attention map 做定位：以「小孩踢足球」为例，采样早期 attention 对球的位置不敏感，随迭代推进，attention map 会清晰地圈出足球所在；同理可定位黄猫、握手位置等。擦除时就显式抑制目标概念对应区域的 attention 激活。

但讲者随即指出纯定位法的泛化缺陷：如果用户故意把 soccer 拼错一个字母，模型语义上仍理解为足球，而按名词精准定位会找不到它。也就是说按词定位的方法没有足够的泛化性，必须配上语义层面的机制——这引出下一个组件。

4. 方法组件二：反向自对比损失（reverse self-contrastive loss）

核心思想一句话：让待擦概念在特征空间里向无关概念靠拢、同时远离它自己的近义词。比如擦「裸体」：把它往「大树」「青草」这类无关概念上匹配（讲者举的直观后果是模型可能给人物生成绿色的内衣裤，因为树是绿的），同时让它远离「胸部」等近义词。普通自对比损失是让概念与近义词靠近，这里是刻意反着来，所以叫 reverse。

近义词与无关词的集合是动态生成的，不用固定词表：挂一个大模型（LLM agent）按语义距离给出近义词、中等距离词与远距离词。讲者解释了为什么不用 T5 特征做余弦相似度：Flux 用的就是 T5，他们试过，T5 特征下与「裸体」最相近的竟然是「瘦」「女孩」这类词，质量明显不如大模型生成的结果。这是「用 LLM 当构词器优于用编码器特征算相似度」的一个具体证据。

5. 方法组件三：双层优化分开「擦」与「留」

训练是 bi-level（双层）的：低层负责擦除，高层负责保证无关概念不受影响，两层各带两个 loss 交替迭代。擦除侧用两条：其一是沿用 ESD 一路的擦除损失；其二是定位侧的 attention 激活抑制。保留侧的逻辑讲者用大白话讲得很清楚：把「nude girl」里的 nude 擦掉，你起码得还生成一个 girl，不能生成个男的出来——保留损失就是约束擦除后的模型在无关概念上与原模型表观一致。

最终擦除效果上，讲者强调三点：擦得干净（不留残余，ESD 式「只擦下半身」的问题不存在）；抗叠加——多个 LoRA 叠起来可以一次擦掉 5–10 个概念而不明显掉效果（擦汽车变轿车的同时，生成 C 罗、蝙蝠侠、绿巨人仍正常）；多概念 LoRA 的合成方式在 Q&A 里也给了：两个就各乘 0.5，三个就各乘约 0.33，等权相加。

6. 能擦什么：实体、抽象、关系三类

定量实验按三类概念组织：实体（具体的人、鞋等）、抽象概念（烟雾效果、艺术风格）、关系（握手、拥抱、亲吻）。关系是这一代基座的新增能力——Flux 对关系的理解相比 SD3/SD 系列大幅提升，所以「能不能把关系也擦掉」成了新问题：CA 擦不掉两只猫握手的「握手」关系，EraseAnything 可以。讲授还展示了更刁钻的案例：擦颜色（红/绿）、擦量词（「五个铅笔」的五、「三只猫」的三）、组合擦除（狗 + 背靠背关系一起擦，结果变成拥抱；教堂 + 爆炸一起擦等)。与 CA 的定量对比上，讲者称在非相关概念准确性上平均高约两个点（字幕口径），其余指标亦更优。

7. 定量实验与 user study

  • 干净程度：用检测模型过擦除后模型的生成图，数值越低擦得越干净。EraseAnything 不是最低的（UCE 更低），但 UCE 的代价是生成图像质量严重受损，EraseAnything 则基本不影响图像质量——讲者的立场是干净与质量要一起看。
  • 对抗攻击鲁棒性：对擦除后模型做 adversarial attack，其抵抗力优于对比方法（指标越低越好，字幕口径）。
  • User study 五个维度：擦除干净程度、无关概念保留、图像质量、prompt adherence（是否还按 prompt 生成）、输出多样性（换 seed 结果仍多样、没有过拟合到擦除权重上）；讲者展示其方法在各维度均居前。

8. Q&A 要点

  • 多概念 LoRA 叠加：等权平均（2 个各 0.5、3 个各约 0.33）直接相加，即目前的做法。
  • 基线方法的基座都是 SD，在 Flux 原生上做擦除的，「应该我们是第一个」。
  • 实现基于 Diffusers 改；做图像/视觉语言模型方向的人容易上手。
  • 讲者个人判断：概念擦除这类工作放到 vision-language model 上做影响力更大、机会更多（他的开放讨论邀请，非论文结论）。

5可迁移

  • 「擦除—保留」双层结构可直接类比到模型编辑与机器遗忘：把目标行为的消除与无关行为的保真拆成两个交替优化层级、各自带独立损失，比单个加权总损失更容易定位是哪一侧在退化。换到 LLM 的 unlearning / 拒答训练上是同一套结构。
  • 用大模型生成对比学习的正负样本集合（近义/远义概念），优于用编码器特征算余弦相似度挑词——讲者给了一个编码器挑词翻车的具体反例（T5 特征下「裸体」的近邻是「瘦」）。凡是需要语义邻域的训练数据构造，这条优先级值得先验采用。
  • 对新架构做方法迁移时，先系统地找「作用点」而不是急着改损失：Flux 没有 cross-attention 层，旧方法的默认改动位置直接不存在；讲者逐块试出 dual-stream block 的过程说明，架构级定位实验的优先级高于损失设计。
