## 一句话总结

这是一场「分体式结构辩护 + 后训练配方公开」的 talk：讲者论证 InternVL 选择 ViT + 两层 MLP + LLM 的分体式结构，是因为它能复用单模态预训练、下限与上限都高，唯一代价（ViT 带来的负载压力）可用 V-L 分离部署换回 1.5–2 倍推理速度；在训练侧，InternVL3 相对 2.5 的进化是原生多模态预训练（图文与纯文本混训）加离线偏好优化 MPO——用 DPO 的相对偏好、绝对质量与生成三项 loss 压住概率塌缩，再以每步采样 16 次估计期望正确率训出的 VisualPRM 做 best-of-N 测试时扩展。整场的底色是：通用多模态后训练在算法上已越来越像「叠数据 + 压分布」，真正的科学问题要去找更「多模态」的任务。

## 核心

### 结构选型：为什么是 MLP 连接件，为什么不用全局注意力

多模态大模型的经典骨架是「ViT 编码 → 展开成 token 序列 → 与文本 token 拼接 → LLM 生成」，真正的设计点只有视觉与语言的语义空间怎么对齐。讲者梳理了三种主流中间件：Q-Former（BLIP 带火，几百 M 参数）、MLP 投影（LLaVA 带火，几 M 到 20M 参数，只有 Q-Former 的 1/10 甚至 1/20）、Flamingo 式 cross-attention（在 LLM 内并行扩出一路 cross-attention，几百 B 模型上可达几 B 甚至几十 B 参数，是三者中最重的）。InternVL 试过之后选了 MLP，理由在 Q&A 与正片里反复出现：**参数量应该集中在 ViT 和语言模型上，中间件不该喧宾夺主**；Flamingo 结构参数极大、收敛更慢，实践中没观测到性能提升。

分体式（ViT 与 LLM 各自单模态预训练、再拼起来对齐）的核心收益是数据复用：LLaVA-1.5 只用 558K 预训练 + 665K SFT 数据就能拿到不错的性能，说明下限极高；而 InternVL 把数据堆到几百 M 乃至几 B 量级时性能还能明显涨，上限同样高。代价是 ViT 引入额外的负载压力——很多 LLM 的超参本就卡在显卡阈值上，多塞一个 ViT 就可能塞不下或变慢。讲者的解法不是改结构，而是改部署（见下节）。

动态分辨率是另一个关键设计：不同图像信息量不同，就该用不同数量的视觉 token 表征——空白图像不必用 256 个 token，遥感图像用 256 个又不够。InternVL 的做法是按原图长宽比映射到预定义分辨率（示例：800×1300 的图映射为 896×1344，切成 6 个 448×448 的图像块），再把原图缩放成 448×448 缩略图与细节块拼在一起编码。实验证据：以 InfoVQA 为例，随着每图最大 patch 数上升，性能先陡升（从 1 个 patch 到阈值能有约 40% 的准确率提升）再趋平。与 Qwen-VL 的区别在切法：对方用 112×112 的小 patch 尽量保持原始分辨率与尺度信息，代价是 patch 间语义太碎、必须每隔若干层插一次全局注意力做 patch 间交互；InternVL 的大 patch 内部自带足够语义，全程窗口注意力、patch 间零交互。讲者的判断很直接：两种策略在通用领域没有本质区别（Qwen2.5-VL 曾领先是数据更好，InternVL3 靠新一版数据反超），所以 InternVL 宁可要「无全局注意力」换来的部署便利。

### V-L 分离部署：把负载压力从问题变成 1.5–2 倍加速

针对 ViT 的负载压力，团队提出 V-L（Vision-Language）分离部署：推理时把 ViT 与语言模型部署在不同节点/集群，图像先在集群 A 由 ViT 编码，embedding 再送到集群 B 的语言模型。集群 B 直接复用现成的 LLM 推理基建（输入本质上是 token embedding 序列），集群 A 复用 ViT 侧优化；讲者给出实践数字：相比每节点整体部署一个多模态模型，**推理速度提升 1.5 到 2 倍**。这套部署反过来给结构上了两条硬约束：中间件必须尽可能小（大了就把优化吃回去，所以用 MLP 而非 Flamingo）；patch 间不能有交互——没有交互时不同 patch 等价于不同图像、直接 batch 推理即可，有全局注意力就得记录 patch 归属并做额外交互，「这个其实就很麻烦了」。这也是讲者不看好一体式结构（见下节）的根本原因：它为省 ViT 而生，但 ViT 的成本已被部署策略摊平。

讲者也顺带回应了一体式（单 LLM + 静态路由 MoE 分离视觉/语言 FFN、丢掉 ViT、只留小 patch embedding）的探索：团队在 Mono-InternVL 里试过，同 setting 下 MMBench 与分体式差约 8 个点。原因在数据复用率——视觉 FFN 随机初始化、纯视觉预训练数据全部作废，必须用多模态数据从头增量训练，下限低、首次见效周期长。讲者的结论：理解任务上分体式明显占优，一体式真正的价值在图文统一生成（感知 ViT 与生成 diffusion 不是一套编码器、语义空间对不齐，是分体式做生成的结构性难题，Emu 用 L2 loss 硬对齐又极难收敛），那里才值得继续探索。Q&A 补了一刀：动态路由他不看好，因为学术界至今没有好的 MoE 训练法，只加负载均衡 loss 训不出比 dense 明显更好的模型；可参考 BEiT-3（静态路由）与后续动态路由工作的对比。

### 训练流程：从渐进式对齐到原生多模态预训练

分体式的训练是两条单模态线加一条融合线：语言侧走 LLM 自己的预训练与后训练，视觉侧走 CLIP 式对比预训练，拼起来后先只训 MLP 做冷启动，再逐步放开。冷启动的动机是随机初始化的 MLP 会把带语义的 ViT/LLM 参数「带坏」：无冷启动时 loss 曲线明显更高，约 50K steps 时差距明显，训到 10 万–20 万步才会被抹平——为了收敛速度还是单独训 MLP。

历史上还有个只出现过一次的「阶段 1.5」：InternViT 做 CLIP 预训练时见的多是通用感知图像（人、车、花园），对表格、海报这类 OCR 图像几乎没见过；于是冻结 LLM、只放开 ViT、用大量 OCR 数据把图表理解能力注入 ViT。到 InternVL2.5，这条已把感知做到接近上限（讲者回忆 78B 模型 OCRBench 约 906 或 910 分，满分 1000），所以 InternVL3 直接砍掉阶段 1.5，重心转到推理与长 CoT。

InternVL3 训练侧最大的变化是**原生多模态预训练**：不再拿训好的纯文本 LLM 做后挂式对齐，而是从 base 语言模型初始化，把大量纯文本数据与多模态数据混在一起一阶段训完。动机是推理数据的不对称：多模态侧的推理 QA（如 GeoQA 一类）难度太低、收益已经不明确，纯文本侧有大量高质量难题；混入纯文本后多模态推理能力明显提升，附带好处是纯文本能力不掉。数据清洗被讲者称为「非常 tricky、非常工程」，细节看技术报告；他强调开源数据已足以把感知与推理做到很好，私有数据更多面向用户体验。

预训练侧还有三个被单列的设计：随机图像压缩（训练时随机把图像压成低质 JPEG，模拟用户随手拍的糊图输入）、square loss reduction、token packing。packing 指把多个样本拼成一条长序列、样本间用 attention mask 隔离，序列内零 padding；讲者给出量化口径：78B 模型训练速度约可加快一倍，且自称是开源社区第一批在多模态训练中引入 packing 的团队。square loss reduction 值得单独记：loss 在 token 维度平均还是样本维度平均，决定每个 token 对梯度的贡献——样本平均训出的模型 benchmark 分数更高，token 平均训出的模型长回答质量更好、用户体验更好。讲者把两种平均统一写成 token 权重 $x^{-\alpha}$ 的形式（其中 $x$ 为样本 token 数）：token 平均对应 $\alpha = 0$ ，样本平均对应 $\alpha = 1$ ，InternVL 取中间态 $\alpha = 0.5$ ，即权重 $x^{-1/2}$ ，分数与体验兼得（细节见 InternVL2.5 技术报告）。

### MPO：用负梯度修剪分布，再用两个辅助 loss 压住塌缩

后训练侧 InternVL 目前用 SFT + MPO。为什么需要 MPO？讲者的比喻是：LM loss 本质是模仿学习，只有正样本；正梯度像拿抹布盖桌上的黑点，盖住黑点的同时也把黑点附近无关的地方一起盖住了——模型学会 ground truth 的同时，也学会了它附近那些「很像但其实是错的」幻觉回复。解法是引入负样本与负梯度，对响应分布做修剪。

负样本对的构造分两类：可校验样本用答对为正、答错为负；不可校验样本用一个 trick——把模型自己的输出当正样本，保留前半段、**在不给图像的条件下续写后半段**，续写结果当负样本，依据是「不看图的回答会比看图的回答差」这一假设，实践效果很好。

但纯 DPO 长期训练会塌缩：它只保证正负样本的相对概率差拉大，不保证绝对概率，正负概率可能同时下降，模型表现就是 CoT 复读、乱码（乱码率口径见下表）。MPO 在 DPO（相对质量/偏好 loss）之上加两项：生成 loss 保证拉大差距的同时正样本绝对概率上升；但这又会引发反向塌缩（正负同步上升、负样本概率也被拉高），于是再加绝对质量 loss 压住负样本概率。三项加权合成即 MPO。收益口径：InternVL3-38B 与 78B 的推理性能分别提升 4.5 与 4.1 个点；2/2.5 世代感知能力也有约 4–5 个点提升。讲者特别强调 MPO 相对 GRPO 的 infra 优势：它是离线算法，用模型 A 采样的数据可以训模型 B，InternVL3 直接复用了 InternVL2/2.5 构造的数据，相当于把最慢的采样成本摊到多代模型上；且 MPO 全部训练数据已开源，取用后训练成本与 SFT 相差无几。Q&A 把两者关系定死：不是二选一——MPO 训完再上 GRPO 还能再涨；算力只够选一个时选 MPO。另一个细节澄清：复读/乱码是 DPO 的 loss 带来的（正样本绝对概率下降→模型「不会说人话」），由 MPO 的辅助 loss 解决，而不是靠负样本本身。

### 测试时扩展：VisualPRM 与「阈值设为零」的噪声哲学

测试时扩展走 best-of-N，选优靠多模态过程奖励模型 VisualPRM。训练数据按 Math-Shepherd 一系的管线构造：对每个 query 采样一条完整 rollout，按双换行切步，每步用不同 policy 续写采样 16 次，以 16 次的正确率作为该步的期望正确率、即过程监督信号。实现上试了两种 PRM：value-based（预测每步期望准确率是否大于零）与 advantage-based（预测这一步是否比上一步更好），前者胜出。原因和方法论都在「噪声」上：16 次采样里有蒙对的答案，期望正确率本身含噪；精细监督会被噪声带偏，而把阈值设为零等于对标签做离散化，监督变粗的同时噪声被抹掉。评测上，VisualPRM 对 MiniCPM、Qwen-VL 等不同 policy 做 best-of-N 都能带来约 7–8 个点的 overall 提升，且明显强于结果奖励模型与投票；N 越大性能持续涨。Q&A 补了个未发表的结果：把 VisualPRM 当 GRPO 的 critic 给过程奖励，比只用结果奖励再高约 2 个点，后来没推进——一是新意不足，二是 on-policy RL 的趋势是尽量少带额外网络。Intern-Omni（给 InternVL 加音频感知）与通专融合的 VisionLLM（用 soft embedding 把 LLM 与检测/分割/生成工具相连：感知任务 8 个 query embedding 够用，图像生成要 64 个）只做了简介。

### Q&A 要点（含讲者对领域状态的判断）

- **能只训 ViT、冻住 LLM 吗？** 可以但上限低：视觉信息以 soft prompt 形式输入，LLM 不放开的话与全放开有明显差距。
- **垂直领域（如零售货架/品牌 logo）怎么灌知识？** 放后训练阶段就够了，不必回预训练注知识；构造对应数据做一版 SFT 与 MPO，正样本用答对的、负样本随便贴个别家品牌名即可，轻量训练就能见效。知识若不方便做成 QA，不带对话模板直接 next-token prediction 灌进预训练也可以——预训练与 SFT 的真正区别是数据质量分层（低质大量放预训练、高质放 SFT），不是格式。
- **ViT 参数堆到 6B 值吗？** 早期在 8B 模型上做过消融：6B ViT 对比 300M ViT 有明确收益，所以后来才换上 6B InternViT；但那是很早的实验，之后没再复验。
- **微调算力门槛**：8B/14B 八卡够用；78B 至少 32 卡才能训得动（不 OOM），64 卡更现实。
- **多模态推理与纯文本推理算法有本质区别吗？** 没有。输出空间都是文本，只是输入多一个图像条件；「就是两拨人在不同的 setting 上做验证」。两边主流都还是结果奖励，InternVL 在研究不引入额外神经网络的过程奖励方案。
- **「随机奖励也能涨点」的争议工作**：讲者转述后续批评——那篇工作把 baseline 压低了，实际是掉点的结果被写成涨点，「算是一个打假」。
- **多模态后训练还有什么学术热点？** 讲者坦言通用领域已越来越像叠数据、搞工程，他的建议是找更「多模态」的科学问题：多模态数学题其实不够多模态（看完题推理全程在文本空间完成），而地标定位一类任务必须在图像空间推理、需要图像与现实世界的映射知识，才是多模态独有的研究对象。
- **InternVL3 相对 2.5 的数据优化**：更多高质量数据，扩了 3D、GUI 数据，近期在扩具身数据。

## 可迁移

- **「参数集中在主干、中间件从简」是可跨项目的先验**：连接件（MLP/projector/adapter）参数膨胀既不涨性能又拖部署；做 post-training 系统设计时，先给中间件定参数预算上限，再谈结构花样。
- **部署约束应前置到架构选择**：V-L 分离部署把「ViT 负载」从结构问题变成调度问题，并反向导出「patch 间零交互、中间件极小」两条硬约束——这正是 RL/infra 侧熟悉的「先定 serving 形态、再定模型形态」。对 coding data 与 agentic RL 的多模态 rollout，同样的分离式编码服务可直接套用。
- **MPO 是离线偏好优化的低成本默认选项**：跨代复用采样数据、成本与 SFT 同级、且压住了 DPO 的概率塌缩；对没有 on-policy 采样预算的团队，它是先于 GRPO 的第一步。负样本构造的「无图续写」trick 也可迁移到任何「条件 ablation 即劣化」的任务（遮掉工具返回、遮掉检索结果）来批量造偏好对。
- **过程监督的噪声哲学**：含噪的细粒度标签（16 次采样的期望正确率）先二值化再训练，反而比精细回归更稳——做 PRM/奖励模型数据管线时，这条比模型结构更先决定成败。

## 疑问 / 下一步

- Square loss reduction 的 $\alpha = 0.5$ 是 InternVL2.5 报告的经验值，讲者未给它随模型规模/任务类型变化的规律；对纯文本 post-training 是否同样成立，talk 未验证。
- MPO 三个 loss 的权重与 BCO 细节讲者全部推给论文（arXiv:2504.10479 及其引用的 MPO 原论文），引用具体数值前需查原文；讲者口径的 +4.5/+4.1 与报告 Table 口径一致，但 benchmark 集合以报告为准。
- V-L 分离部署只给了 1.5–2 倍的结论数字，论文「近期发布」未出；ViT 编码服务与 LLM 服务的配比、embedding 传输开销占比等工程参数尚无公开来源。
- 「原生多模态预训练」中纯文本与多模态数据的配比讲者没有给出， InternVL3 在数学推理上与纯文本混训的增益幅度也只有定性说法（「非常明显的提升」），需查报告消融。
