2一句话总结

Levine 的主张是把 LLM 的「预训练 → 后训练」范式完整搬到机器人上：VLA 靠模仿学习拿到通用先验，但成功率、鲁棒性与执行速度只能靠 RL 后训练补上；其落地形态是 Physical Intelligence 的 RECAP（π*₀.₆）——用一个分布型价值函数给每条经验（包括失败轨迹与人工纠错）标注优势，再把优势作为条件喂回策略，让通用 VLA 在真实部署中边干边学、最难任务上吞吐翻倍、失败率约减半。

1. 背景/问题：模仿学习的天花板，就是示范者的天花板

这是他 2025 年以来多场公开演讲（IROS 2025 精细操作研讨会等，公开报道口径）反复讲的总纲：当前 VLA 本质上仍是一个通用型模型的原型——能在多种机器人平台上训练、表现出灵巧流畅的控制，但几乎只用模仿学习评测过，从未被显式优化过任务成功率、鲁棒性或执行速度。模仿学习有三笔结构性欠账：

  • 上限锁定：策略只能和示范数据一样好（"can only be as performant as demonstration data"），示范里的次优动作、犹豫与绕路会被一并复制；
  • 误差累积：行为克隆的分布外漂移没有纠偏机制，出错后滑向没见过的状态、越偏越远；
  • 失败不可回收：部署中真实发生的失败轨迹——恰恰是最贴合当前策略分布的数据——在纯模仿管线里只能丢弃。

类比 LLM 非常直接：预训练（SFT 式的模仿）给出「会做事」的先验，但把成功率从 80% 推向 99% 的那一段，靠的是 RLHF/RLVR 式的后训练。机器人缺的正是这一段。

2. 方法/设计：RECAP——把 RL 改写成「带优势条件」的模仿

Levine 团队的答案是 RECAP（RL with Experience and Corrections via Advantage-conditioned Policies），2025 年 11 月随 π₀.₆（arXiv:2511.14759，Physical Intelligence）发布。其关键选择是不用策略梯度硬啃 4B 级 flow-matching VLA*，而是把 RL 改造成条件生成问题：

  1. 先训一个价值函数：分布型价值函数 $V$ 评估「当前状态离任务成功还有多远」（公开整理口径：对归一化的成功所需时间建模，完成越快的轨迹回报越高），它同时给出进度估计；
  2. 给数据中的每个动作标优势：动作级优势 $A$ 由价值函数的进度估计导出——执行该动作后进度是否超出期望；再二值化为改善指示（improvement indicator，即「Advantage: positive/negative」式的文本条件）；
  3. 优势条件策略：策略以指示符为条件训练，可示意写成 $\pi(a_t \mid o_t, \ell, \mathbb{1}[A_t > 0])$ （ $\ell$ 为语言指令）；部署时恒定条件在「positive」一侧，等于在推理时把策略拨向「比数据平均水平更好」的那部分行为分布。

数据侧是三类异构经验的混合：示范（遥操作初始数据）、自主经验（on-policy 部署 rollout，含成功与失败）、专家纠错（coaching——机器人在自主执行中出错时，专家遥操作接管给出纠正段）。这正是 RECAP 名字里 Experience 与 Corrections 的来源：失败轨迹不再废弃，价值函数负责从里面榨出信用分配。训练流程上，RECAP 先以离线 RL 预训练出通用 VLA π₀.₆，再通过真机数据采集把通用模型专化（specialize）到下游任务——与 LLM 的「通用预训练 → 任务后训练」一一对应。他公开演讲中还提到一个互补方向：把 RL 练出的策略知识再蒸馏回 VLA*，以及给 VLA 加 CoT 式指令微调，都是同一张后训练菜单上的条目（公开报道口径）。

3. 实验/实战：从实验室任务到真实家庭与专业设备

π₀.₆ 论文（摘要口径）给出的实证是三个真实场景：在真实家庭里叠衣服、可靠地组装纸箱、用专业意式浓缩咖啡机做咖啡。在最难的任务上，完整 RECAP 流程相对基线吞吐量（单位时间完成数）超过翻倍、失败率约减半*（"more than doubles task throughput and roughly halves the task failure rate"，论文摘要原文口径）。

吞吐这一项值得注意：它意味着 RL 后训练优化的不只是「成不成」，还有「快不快」——因为价值函数内建了对完成时间的建模，磨蹭的成功轨迹回报低于干脆利落的成功轨迹，策略被同时推向可靠与高效。Physical Intelligence 官方博客还给出过长时间连续运行的演示口径（如咖啡任务长时间连续作业、连续叠数十件衣物），属公司自报、未经独立基准验证，此处只作量级参考。

4. 结论/观点：后训练是机器人基础模型的「缺失的一段」

以下按讲者一贯公开论点重组，均非本场逐字原话：

  • VLA 只是起点不是终点：模仿预训练解决「有没有」，RL 后训练解决「好不好」；评测 VLA 只看演示成功率，等于只考了上半场。
  • RL 要规模化，先要把问题改对：在超大生成式策略上直接跑策略梯度既不稳定也难整合异构数据；「价值函数 + 优势条件」把 RL 变成带标签的条件模仿，示范、自主经验、人工纠错第一次能进同一个训练池——数据回路的设计比算法花样更重要。
  • 失败数据是资产不是垃圾：部署飞轮的燃料恰恰是失败与纠错；谁的系统能把真实部署中的失败自动转成训练信号，谁的模型就能随部署时长复利增长。这与他的自我改进飞轮叙事一致：遥操作训初始策略 → 真实部署采集反馈 → 策略迭代更新，循环往复。
  • 分工而非替代：RL 后训练不取代模仿预训练；没有广预训练攒下的通用先验，RL 无从在这么大的状态空间里探索。范式是「模仿给先验、RL 做优化」的接力。

5可迁移

  • 对 coding data / RL infra 工作的直接可试点：优势条件 = 给轨迹打标而不是筛轨迹。RECAP 拒绝丢弃坏数据——用价值函数给每步标「好于/差于期望」，再以标签为条件训练；对 agent 轨迹数据同理：失败 rollout 不必整批扔，按步级优势重加权或条件化，能把部署中真实分布的失败样本变成恢复行为的训练集。这比「只留成功轨迹做 SFT」的管线多回收了一大块数据。
  • Infra 视角的启发：RL 后训练的主要工程量在数据回路而非更新公式——示范、自主 rollout、专家接管纠正三类数据的配比、版本与回灌节奏，才是 π*₀.₆ 式飞轮的本体；做 agentic RL infra 时，应先把「纠错数据如何自动捕获与标注」设计成一等公民，再谈算法。
  • 评测口径：成功率之外应同时报吞吐/任务耗时——价值函数内建时间成本后，策略会自发变快；只报成功率会漏掉 RL 后训练一半的收益。

6疑问 / 下一步

  • RECAP 的价值函数需要新任务的成败标注来冷启动：换到全新任务时，要多少条带标注 rollout 才能训出可用的优势信号，论文与博客都未给出清晰的样本量曲线——这是判断该配方能否横向复制的关键。
  • 优势条件是二值化的（positive/negative），粒度明显粗于连续优势；这种粗化在更精细的灵巧任务上会不会成为瓶颈，公开材料未见消融。
