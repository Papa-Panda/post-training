## 一句话总结

Held 这场沿着自己实验室（RPAD，与 Zackory Erickson 的 RCHI 实验室合作）的一条线讲两件事：辅助穿衣如何从「仿真里训一个 RL 策略」的单点突破，演进为「点云策略 + 策略蒸馏 + 引导式域随机化 + 力约束安全层」的完整系统（17 人 510 次试验、平均穿过手臂长度 86%）；以及当奖励函数写不出来时，让 VLM 看图打偏好标签、从偏好里学奖励（RL-VLM-F），把奖励设计本身自动化——穿衣任务的「穿衣进度 + 轻柔接触」正是这种难手写奖励的典型样本。

## 核心

### 1. 背景/问题：辅助穿衣是「与人接触的柔性物体操作」，难在三处叠加

穿衣辅助的服务对象是老年人与残障人士（无法独立穿衣者），但任务本身是机器人操作里最难的一类组合：**衣物是三维柔性体**（袖子会塌、会皱、会被手臂遮挡）；**人是不可控的**——体型、姿势、配合度因人而异，早期工作往往靠「固定服装 + 固定手臂姿势」的强假设绕开；**接触即风险**——机器人始终贴着人体工作，力过大就是伤害。因此这个任务同时考验感知（遮挡下的部分可观测）、策略（长程柔顺操作）与安全（力约束），Held 实验室的做法是把三者拆开、逐个用学习方法补上。

### 2. 方法/设计之一——穿衣策略：让 RL 在「部分点云」上学，再蒸馏成一个策略

代表作 One Policy to Dress Them All（RSS 2023，与 Yufei Wang、Zhanyi Sun、Zackory Erickson 合作）的主线：

- **感知表示**：输入是单台深度相机给出的**部分点云**——点云对不同衣物、手臂姿势的几何变化天然更稳健，比 RGB 更容易跨服装泛化；
- **RL 训练**：在仿真中用 RL 训穿衣策略，关键在策略与 $Q$ 函数的架构设计（点云编码方式决定了部分可观测下能不能学出有效策略）；奖励侧的经典设计是「穿衣进度」——手臂被袖管「包含」的深度越深奖励越高，未套入时则惩罚末端执行器到袖口特征的距离（按公开论文口径转述）；
- **策略蒸馏**：先按手臂姿势范围分段训多个专家策略，再蒸馏成一个在宽姿势范围上都工作的单策略——「One Policy」的由来；
- **仿真到真实**：用 **guided domain randomization**（引导式域随机化）收尾——让带观测随机化的策略去模仿无随机化策略的行为，得到可稳健迁移真机的策略。

真机评测是 17 名参与者、510 次穿衣试验（多姿势、多服装），平均能把衣物沿手臂穿至 **86% 的手臂长度**，且 7 点李克特量表主观评价显著优于对照基线（论文摘要口径）。

### 3. 方法/设计之二——安全：力仿真不了，就把力约束单独学出来

穿衣策略学得再好，没有安全层不能上真人。2024 年的 Force-Constrained Visual Policy（RA-L，与 Zhanyi Sun、Yufei Wang、Zackory Erickson 合作）处理的是这件事，其设计判断很值得学：**柔性衣物与人体交互的力在仿真里做不准**，于是不要硬仿真——把系统拆成两半：

- **视觉穿衣策略**仍在仿真中用 RL 训（多体型、多姿势、多服装）；
- **力动力学模型**直接从真实世界数据学（预测给定动作会产生多大接触力）；

部署时把两者拼成一个**带约束的优化问题**（示意式重构）：找既能推进穿衣进度、又不越过力上限的动作，可写为满足约束 $\hat{F}(o, a) \le F_{\max}$ 的前提下最大化进度（ $\hat{F}$ 为学得的力预测模型， $o$ 为观测， $a$ 为候选动作）。10 名参与者、240 次试验的人体研究中，该系统大幅优于此前基线（论文摘要口径）。配套的还有公开报道提到的「对轻柔行为给奖励」的温和性设计——温柔不是靠事后限幅，而是同时写进训练信号里。

### 4. 方法/设计之三——奖励建模：与其让 VLM 打分，不如让它选偏好

穿衣进度、轻柔程度这类奖励，靠工程师手写既慢又脆。这正是这场后半段的主题：RL-VLM-F（ICML 2024，与 Yufei Wang、Zhanyi Sun、Jesse Zhang、Zhou Xian、Erdem Bıyık、Zackory Erickson 合作）给出的方案是：

- 只给一句任务目标的**文字描述**和机器人的**图像观测**，查询视觉语言基础模型（如 GPT-4V），让它对**成对观测**给出偏好（哪张图更接近目标）；
- 关键设计：**不要让 VLM 直接输出奖励数值**——直接打分噪声大、不一致；而偏好标签更稳，可按 Bradley–Terry 式偏好模型拟合出奖励函数。设两段观测的回报估计为 $R_1$ 与 $R_2$ ，偏好概率可写成：

$$P(\tau_1 \succ \tau_2) = \frac{\exp R_1}{\exp R_1 + \exp R_2}$$

- 拟合出的奖励再喂给标准 RL 训练策略。实验横跨经典控制、刚性/铰接/柔性物体操作，在相同假设下（无人类监督）优于此前用大预训练模型生成奖励的方法（论文摘要口径）。后续工作进一步把 VLM 反馈推进到**真实世界离线 RL**（arXiv:2411.05273，RPAD 团队 2024 年预印本）。

### 5. 结论/观点：一条「奖励越来越便宜、安全越来越独立」的演进线

以下按讲者一贯公开论点重组，均非本场逐字原话：

- **RL 在辅助任务上可行，但前提是表示与架构先行**：穿衣这种长程、高遮挡任务能用 RL 训出来，靠的是点云表示与 $Q$ 函数设计的配合，而不是更大规模的试错；
- **泛化靠「分段专家 + 蒸馏」，部署靠「随机化模仿」**：与其指望单个策略一次学遍所有姿势，不如分段训专家再蒸馏，并用引导式域随机化做 sim2real 的最后一公里；
- **安全约束不该和策略揉在一起学**：力做不准仿真时，把安全拆成独立的力模型 + 约束优化层，是比「在奖励里加力惩罚」更可控的做法——约束是硬门限，惩罚只是软偏好；
- **奖励设计的未来是「模型出偏好、人定任务描述」**：VLM 奖励把奖励工程从「写函数」变成「写任务描述 + 抽查偏好质量」，这与他在更大学术语境中「通用策略缺精度、需要分层补上子目标与反馈」的判断（2026 年 GRASP 演讲摘要口径）是同一条线：反馈的来源要规模化，策略的精度才有处可学。

## 可迁移

- 对 coding data / RL infra 工作的直接可试点：**「偏好拟合奖励」优于「模型直接打分」**。RL-VLM-F 的教训对用 LLM/VLM 做轨迹评分完全平移：让模型对**一对轨迹**做相对偏好、再拟合标量奖励，比让模型逐条输出 0–10 分更稳定、更抗噪声——做轨迹级 verifier / reward 数据管线时应默认成对比较，用标量分只作粗筛。
- Infra 视角的启发：**把安全做成独立约束层，而不是奖励里的惩罚项**。agent 场景同理：权限、删除、成本上限这类要求，用动作执行前的硬约束校验（独立模型/规则层）比在 reward 里扣分更可靠——扣分可以被策略「权衡掉」，硬约束不会。
- sim2real 的迁移手法可借鉴：先分段训专家、再蒸馏、最后用「带噪学生模仿干净教师」的引导式随机化收尾——这套顺序对「仿真/自举数据 → 真实分布」的 agent 训练同样成立，比直接域随机化从零训更稳。

## 疑问 / 下一步

- 穿衣系统评测中参与者以健康人为主、姿势配合度可控；面对真实照护场景中无法配合、会移动的手臂，86% 的覆盖度还剩多少，公开材料未给这类分层数字。
- RL-VLM-F 的偏好质量依赖 VLM 的视觉判断，在穿衣这类「进度差异很细微」的任务上偏好标签噪声如何，目前未见针对该任务的专项验证。
